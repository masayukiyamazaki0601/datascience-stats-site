Chapter 01 / Unit 01 — 比較ドラフト A／謎解きミステリー調

事件は「平均★4.2」にあり — データの種類と尺度

このUnitでできるようになること
  • 「平均していいデータ」と「平均してはいけないデータ」を見分けられる
  • データのレベル(名義・順序・間隔・比例)を「証拠」として説明できる
File 01 — 依頼

「数字は順調なのに、なぜ客が減る？」

深夜0時。あなたの元に1通のメールが届きました。

📧 依頼メール — こだわり酒場「北斗」店主より

「3ヶ月前から客足がぱったり。でも、数字はぜんぶ順調なんです。アンケートの満足度は平均★4.2、アプリ会員も毎月増えている。どうして客が減るんでしょうか…。うちの数字、どこかおかしくないですか？」

あなたはフリーのデータ調査員。翌日、店を訪ねると、店主がノートを差し出しました。そこには店の数字がびっしり。まずはこのノートを証拠として調べることにします。

📓 証拠ノート — 店主のメモ(抜粋)
  • 先月の来店2,000人全員のデータ → 「平均客単価3,400円。まずまず」
  • 今月の来店500人のアンケート → 「全体の満足度は74点くらいだろう」
  • お客様アンケート → 「平均★4.2。なのに客が減る…」
  • 会員IDは1001〜2088 → 「平均IDを出すと、会員は新しい方に寄ってる？」

このノートを読み解くには、統計に2つの役割があることを知っておく必要があります。事件を解く前に、道具をそろえましょう。

  • 役割1「まとめる」= 記述統計: 手元にあるデータ全部を集計して1枚にまとめる。例: 来店2,000人全員から平均単価を出す。
  • 役割2「当てる」= 推測統計: 一部のデータから、見えていない全体を推定する。例: 500人のアンケートから全来店者の満足度を当てる。

店主はどちらも使っています。さて、ノートの怪しい2つの数字——「平均★4.2」と「平均ID」——を、次のFileから1つずつ検証していきましょう。

✏️ 途中確認 — 記述か、推測か

「先月の来店者2,000人全員のデータをまとめて、平均客単価3,400円と報告する」のは、統計のどの役割でしょう？

答えの理由
手元にある2,000人全員を集計しただけなので「記述統計」です。一部から、まだ見えない全体を推定するのが推測統計でした。この区別は、あとで「母集団と標本」を学ぶときの土台になります。
File 02 — 手がかり①「平均★4.2」

「★の平均」は、ほんとうに客の気持ち？

店主は胸を張ります。「満足度は平均★4.2。これってすごくないですか？」

★のデータをじっと見ると、ある罠が見えてきます。★には順番はあるけれど、星と星のあいだの幅は人によってまちまちです。「★4と★5の差」と「★2と★3の差」は、本当に同じ大きさでしょうか？ レビューを書く人の気分で変わりますよね。

こうした「順番つきの分類」を順序データと呼びます。順序データには、さらにやっかいな性質があります。平均★4.2でも、中身は大違い。証拠ノートに、こんな2店の記録が残っていました。

📓 証拠ノート — どちらも「平均★4.2」の店

店X: ★3が10件・★4が60件・★5が30件 → 「ふつう〜満足」に1つの山

店Y: ★1が20件・★5が80件 → 「大好き」と「怒って★1」(2割)に分裂

→ 平均だけを見ると、どちらも同じ「★4.2」。でもお客様の感想のようすは、まったくの別物です。

ここで、あなたは違和感に気づきます。「店Yのお客様の2割は★1を付けているのに、『平均4.2』とだけ報告されると、良い店にしか見えない。」★のデータは、平均ではなく「★4以上の割合」や「★1の割合」で見せるのが正しい報告です。この「罠」が、今回の事件の伏線になります。

✏️ 途中確認 — ★レビューの正体

レビューの★（★1〜★5）のデータは、レベルでいうとどれでしょう？

答えの理由
★5のほうが★1より「良い」という順番はありますが、★と★のあいだの幅が等しい保証はありません。「平均4.2」は二極化などの内訳を隠すので、割合や分布とセットで報告するのが安全です。
File 03 — 手がかり②「平均IDの怪」

「平均会員ID」は、何も語らない

店主ノートの最後のメモを、もう一度見てみましょう。

📓 証拠ノート — 店主の迷言

「会員IDの平均が1,504になった。つまり会員は『新しい方』に寄ってる？ 新規会員が増えてる証拠かな？」

これは残念ながら、なんの意味もない計算です。会員IDは「お客様に順番に振った、ただの番号」。1,001番でも2,088番でも、そこに「大きい・小さい」の意味はありません。

こういう「分類するだけ」のデータを名義データと呼びます。会員ID・郵便番号・電話番号・性別コード（1＝男性, 2＝女性）は、見た目が数字でも実は名義。足したり平均したりするのは、文字を足すのと同じくらい無意味です。名義データで出せるのは「いちばん多いもの」（最頻値）と「それぞれの割合」だけです。

💻 聞き込みメモ — パソコンは止めてくれない

パソコンは「名義なのに計算してしまう」ミスを止めてくれません。平均IDも、実行すればちゃんと結果が出ます。だから「コード上の型（int/object）」ではなく、「この列は何を表すか」で判断しましょう。

# 実行すると計算できてしまう……が、意味はない
import pandas as pd
df = pd.DataFrame({"会員ID": [1001, 1002, 1003, 1004, 1005]})
df["会員ID"].mean()   # → 1003.0（だから何？ という話）

✏️ 途中確認 — 会員IDの正体

データに「会員ID（101、102、103…）」という列があります。このデータのレベルはどれでしょう？

答えの理由
会員IDは数字に見えますが、順番に意味はなく「ただの番号」。分類（名義）なので、平均を出しても意味がありません。判断の基準は「数値型かどうか」ではなく「その列が何を表すか」です。
File 04 — 手がかり③「気温20℃のアリバイ」

「今日は2倍暑い」——は言えない

店主のノートには「夏は気温が上がるのに客が減る」とあります。気温と客数の関係を調べるため、気温のデータも確認しましょう。ここにも、ひそかな罠があります。

📓 証拠ノート — 天気のメモ

「7月は平年より2℃高い。去年より2倍暑い、ってことか？」

気温は「数」のデータですが、数字にクセがあります。0℃は「熱がまったくない」という意味ではないこと、わかりますか？ −5℃だって存在します。だから「20℃は10℃の2倍暖かい」とは言えません。「比（2倍）」を語るには、0が本当の「無」でなければいけないからです。

差を計算できるけれど、比まで言えないデータを間隔データと呼びます。同じ仲間に西暦があります。「2026年は1013年の2倍」は変ですよね。西暦の0年は「時間がゼロ」ではなく、基準（紀元）を決めただけ。だから0＝「無」ではないのです。

  • 間隔データの例: 気温（℃）・西暦・時刻（時）
  • できること: 「差」を計算できる（20℃と10℃の差は10℃。2026年は2016年より10年後）
  • できないこと: 「2倍」を言う（20℃は10℃の2倍ではない）

✏️ 途中確認 — 気温のアリバイ

「気温 20℃」のデータは、どのレベルでしょう？

答えの理由
気温の0℃は「熱が無い」を意味しないので間隔尺度です。「20℃は10℃の2倍暖かい」とは言えません（−5℃も存在します）。「0が本当の無かどうか」が、間隔と比例の分かれ道になります。
File 05 — 手がかり④「滞在0分の証言」

「0分」は、何も滞在していない——これが決め手

店長の新しい試み「飲み放題120分」。あなたは滞在時間のデータを眺めながら、「0」という数字に注目します。

📓 証拠ノート — 「0」の意味を比べる

滞在時間 0分 = まったく滞在していない（0が本当の「無」）

注文金額 0円 = 何も買っていない（0が本当の「無」）

気温 0℃ = 熱が無いわけではない（さっきのデータ）

このちがいが、事件を解く鍵です。0が本当の「無」を意味するデータを比例データと呼びます。比例データなら「2倍」が言えます。「滞在60分は30分の2倍」「注文1,000円は500円の2倍」——どちらも自然ですよね。身長・金額・滞在時間・来店回数はすべて比例データで、平均も比も自由に使えます。

いっぽう、さっきの気温は0が「無」ではないので比例ではなく間隔。まとめると、こうです。

間隔データ比例データ
0の意味基準を決めただけ（0℃・西暦0年）本当の「無」（0円・0分・0cm）
例気温・西暦身長・金額・滞在時間・来店数
「差」✅ 言える✅ 言える
「2倍」❌ 言えない✅ 言える

✏️ 途中確認 — 滞在時間の証言

「滞在時間 0分 ＝ まったく滞在していない」というデータ（滞在時間）の尺度はどれでしょう？

答えの理由
滞在時間の0分は「まったく滞在していない」という本当の無を意味します。だから比例尺度。「60分は30分の2倍」と比も言えます。0の意味で気温（間隔）と見分けるのがコツです。
File 06 — 解決編

容疑者は4人。全員の身分を「レベル」で割り出せ

証拠を並べてみると、店の数字を誤読させた「容疑者」は、データの4つのレベルだという結論にたどり着きます。レベル順に並べると、こうなります。

レベルよび方たとえばできること
1名義血液型・都道府県・会員ID分類するだけ
2順序★レビュー・5段階評価順番をつけられる
3間隔気温（℃）・西暦差を計算できる
4比例身長・金額・時間「2倍」も言える
Level 1名義分類するだけ
Level 2順序＋ 順番をつける
Level 3間隔＋ 差を計算
Level 4比例＋ 「2倍」も言える

図1: レベルが上がるほど「できること」が増える。レベル1・2では平均できない

「これはどのレベル？」と迷ったら、容疑者に3つの質問をぶつけるだけでOKです。

  1. 順番に意味がある？ → ない＝名義（レベル1）
  2. 値と値のあいだは同じ幅？ → 同じ幅とは言えない＝順序（レベル2）
  3. 0は「何もない」？ → はい＝比例（レベル4）／いいえ＝間隔（レベル3）

そして、この事件の結論は1つだけ。「平均してよいのは、数（レベル3・4）のデータだけ」。レベル1・2は「いちばん多いもの」や「◯◯以上の割合」で伝えましょう。店主の失敗は、★とIDという「平均してはいけない数字」に平均を出し、間違った安心をしてしまったこと——いわば「意味を考えずに平均した人」が真犯人でした。

✏️ 最終確認 — あなたへの検察からの質問

事件の証拠品「会員ID（101、102、103…）」のレベルはどれでしょう？

答えの理由
会員IDは数字に見えますが、順番に意味はなく「ただの番号」。分類（名義）レベルです。パソコン上の型ではなく「その列が何を表すか」で判断する——これが調査員の基本です。

──解決後のエピローグ。店主は報告のしかたを改め、満足度を「★4以上が70%」「★1が8%」で伝えるようにしました。すると初めて「★1の理由＝会計待ちが長い」が見えてきて、レジを増やしたところ、客足は少しずつ戻り始めました。数字は悪さをしません。使い方を間違えた人間が悪さをするだけです。あなたの調査は、これにて解決。次の事件（Unit②）も、楽しみにしていてください。

📝 事件後の最終確認: データの種類と尺度（6問）

正解 0 / 6問

Q1. 「東京都」「大阪府」「北海道」…のような都道府県データは名義尺度です。このデータに「平均」を出すことはできるでしょうか？

解説を見る
都道府県は名義尺度なので、四則演算は意味を持ちません。仮に「北海道=1, 青森=2, …」と番号を振って平均を出しても「都道府県コードの平均=24」と言っているだけで、何の情報にもなりません。出せるのは最頻値（最も多い都道府県）や各カテゴリの割合（例: 東京都在住が12%）です。

Q2. ネットショップのレビューで「★1〜★5」の平均が「4.2」と報告されています。★のデータはどの尺度で、この報告は厳密にはどういう問題があるでしょう？

解説を見る
★は順序尺度です。「★4と★5の差」と「★2と★3の差」が人によって同じとは限らないため、平均は厳密には不適切です。しかも平均は分布を隠します。同じ平均★4.2でも「★5ばかりの店」と「★5と★1が混在する二極化した店」では意味がまったく違います。「★4以上の割合」や中央値＋分布で報告するのが望ましいです。

Q3. 次のうち「比例尺度」のデータはどれでしょう？

解説を見る
比例尺度の0は「無」を意味します。身長0cm＝身長がない、金額0円＝何も払っていない。だから「170cmは85cmの2倍」と比が成り立ちます。一方、気温0℃は「熱がまったくない」を意味しないので間隔尺度です（-5℃も存在します）。「20℃は10℃の2倍暖かい」とは言えませんね。身長・滞在時間・来店数は比例尺度です。

Q4. データ分析の現場で「コード上は数値(int)なのに、実は名義尺度」という落とし穴があります。次のうち、その例に当てはまるのはどれでしょう？

解説を見る
郵便番号・会員ID・商品コード・電話番号は、見た目は数字ですが「足したり平均したり」する意味がありません（郵便番号の平均を出しても無意味）。滞在時間や購入金額は量を表すので平均できます。数値型かどうかではなく、その列の「意味」で尺度を判断しましょう。

Q5. 「西暦（2010年・2026年など）」のデータは、どの尺度でしょう？

解説を見る
西暦の0年は「時間がゼロ」を意味するのではなく、基準（紀元）を決めただけなので間隔尺度です。「2026年は1013年の2倍」とは言えませんね。差（何年後か）には意味があります。

Q6. アンケートで「性別」を 1＝男性・2＝女性 のように数字にコード化しました。この列の正しい扱い方はどれでしょう？

解説を見る
コード化しても意味は変わりません。1・2はただのラベル（名義尺度）なので、平均や引き算は無意味。正しくは「男性が40%、女性が60%」のように割合で集計します。
