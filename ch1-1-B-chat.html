Scene 01 — 炎上ツイート

「データが嘘つき」なのか、読み手がバカなのか

🐂 炎の牛まる公式 @honoo_ushimaru・3時間前
新メニュー「炎のカルビ」、お客様アンケートで☆4.2を獲得🔥 なのにぜんぜん売れない。データって、こんなに当てにならないものなんですかね…
📊 豆田(データ分析) @mameda_ds・3時間前
ちょっと待った。それ、たぶん数字の「読み方」が間違ってますよ。お店に伺ってもいいですか?

翌日。焼肉チェーン「炎の牛まる」2号店に、データアナリストの豆田がやってきました。店長のジンが腕を組んで待っています。

🐂
ジン店長
話は聞いた。だがな、☆4.2は間違いなく「良い数字」だろ? それで売れないのは、データに騙されてるってことじゃないか?
📊
豆田
データは嘘をつきません。数字の扱い方を間違える人間が、知らないうちに嘘をつくだけです。まず、統計には2つの役割があるのを知っていますか?
🐂
ジン店長
役割? 足すとか引くとか、計算の話か?
📊
豆田
違います。1つ目は「まとめる」＝記述統計。手元にあるデータ全部を集計して1枚にまとめること。2つ目は「当てる」＝推測統計。一部のデータから、まだ見えない全体を推定することです。
🐂
ジン店長
……例えば?
📊
豆田
今週の注文1,000件全部をまとめて「平均客単価3,200円」と報告するのが記述統計。いっぽう、来店した500人にだけ聞いて「全員だったら満足度74点くらいだろう」と当てるのが推測統計です。あなたはどっちも無意識にやってますよ。
🐂
ジン店長
へえ…。で、それが☆4.2とどう関係するんだ?
📊
豆田
それが今日の本題です。アンケートの答えかた、見せてもらえますか? ——ああ、やっぱり。ここに問題があります。

✏️ 途中確認 — 記述か推測か

ある店で「先週の注文1,000件すべて」のデータをまとめて「平均単価3,200円」と報告しました。これは統計のどの役割でしょう？

答えの理由
手元にある1,000件すべてをまとめただけなので「記述統計」です。「一部の500人から全体20万人を当てる」ように、まだ見ていない対象を推定するのが推測統計でした。
Scene 02 — アンケートを解剖

「平均☆4.2」は、数字の化けの皮

📊
豆田
見つけました。ここです。アンケートの設問が「このメニューを☆の数で教えてください」で、集計が「平均☆4.2」になっています。
🐂
ジン店長
☆4.2を出して何が悪い。4.2だぞ、4.2。5点満点で上から2番目の数字だ!
📊
豆田
問題はそこです。☆には順番はあるけど、星と星のあいだの幅が等しい保証がない。だから☆は「順序データ」というレベル。☆の平均は、厳密には計算してはいけない数字なんです。
🐂
ジン店長
「★4と★5の差」と「★2と★3の差」が同じかどうか、なんて誰にもわからんだろ。そんなの気にしすぎだって!
📊
豆田
気にしすぎではありません。平均は中身を隠します。同じ「平均☆4.2」でも、こんな2店があったらどう思いますか?
📊 豆田 @mameda_ds
店X: ☆3が10件・☆4が60件・☆5が30件 → 「ふつう〜満足」に1つの山
店Y: ☆1が20件・☆5が80件 → 「大好き」と「怒って☆1」(2割)に分裂
どちらも平均☆4.2。でも行きたいのはどっち?
🐂
ジン店長
……店Yは2割の客が☆1を付けてるのに、平均だけ見ると名店だ。怖いな。
📊
豆田
でしょう? あなたのお店も、☆1に「会計が遅い」「網が汚い」って本音が隠れてるかもしれません。☆は「☆4以上の割合」「☆1の割合」で報告するのが正解です。
🐂
ジン店長
くっ……まさか「平均」にそんな落とし穴があったとは。で、結局☆は「レベル」でいうと何なんだ?

✏️ 途中確認 — ☆のレベル

レビューの☆（☆1〜☆5）のデータは、レベルでいうとどれでしょう？

答えの理由
☆5のほうが☆1より「良い」という順番はありますが、☆と☆のあいだの幅が等しい保証はありません。「平均☆4.2」は二極化などの内訳を隠すので、割合や分布とセットで報告するのが安全です。
Scene 03 — 会員データの罠

「平均会員No.」は、数字のサラダ

豆田が会員データの画面を開くと、そこには奇妙な集計結果が並んでいました。

🐂
ジン店長
会員No.は1001から始まるから、平均を出せば「会員の平均が新しい方に寄ってる」ってわかるだろ? これで新規獲得が好調って証明できるんじゃないか?
📊
豆田
それはですね、「血液型の平均」を出すのと同じくらい意味がない計算です。会員No.は、お客様に順番に振ったただの番号。1,001番と2,088番に「大きい・小さい」の意味はありません。
🐂
ジン店長
でも、数字じゃないか。数字なら平均出していいんじゃないのか?
📊
豆田
郵便番号だって数字ですよ。その平均を出して「平均郵便番号は×××」って言って、何の役に立ちます? 会員No.・郵便番号・電話番号・性別コード（1＝男性, 2＝女性）——こういう「分類のラベル」を名義データと呼びます。
🐂
ジン店長
じゃあ名義データで出せる数字は何もないのか?
📊
豆田
ありますよ。名義データで出していいのは「いちばん多いもの」（最頻値）と「それぞれの割合」だけ。たとえば「来店客の血液型はO型が35%で最多」みたいに。会員の新規獲得が知りたいなら、会員No.の平均ではなく「登録日」で見ましょう。
💻 豆田の補足 — パソコンは止めてくれない 
# 実行すると計算できてしまう……が、意味はない
import pandas as pd
df = pd.DataFrame({"会員No.": [1001, 1002, 1003, 1004, 1005]})
df["会員No."].mean()   # → 1003.0（で？ という話）

コード上の型が「数値（int）」でも、列の意味がラベルなら平均は無意味。判断基準は型ではなく「この列は何を表すか」です。

🐂
ジン店長
……勉強になるな。それで、この「名義」とか「順序」とかって、他にも種類があるのか?
📊
豆田
あります。あと2つ。次の現場でお見せしますよ。

✏️ 途中確認 — 会員No.のレベル

データに「会員No.（1001、1002、1003…）」という列があります。このデータのレベルはどれでしょう？

答えの理由
会員No.は数字に見えますが、順番に意味はなく「ただの番号」。分類（名義）なので、平均を出しても意味がありません。判断の基準は「数値型かどうか」ではなく「その列が何を表すか」です。
Scene 04 — 夏の気温データ

「2倍暑い」と言ったら、データ博士が怒ります

📊
豆田
次は売上データですね。あれ、このメモ……「7月は平年より2℃高い。つまり去年より2倍暑い。だから肉が売れるはず」? これは店長の手書きですか?
🐂
ジン店長
そうだ。気温が高けりゃ焼肉だろ? 20℃は10℃の2倍の暑さ。そう考えて仕入れを2倍にした!
📊
豆田
それは大事故です。気温は「数」のデータですが、0℃が「熱がまったくない」を意味しないことを知っていますか? −5℃だってありますよね。
🐂
ジン店長
0℃が……「熱が無い」じゃないのか?
📊
豆田
「熱の無さ」を0にしたかったら、絶対温度（ケルビン）で測る必要があります。℃の0は、氷ができる温度を基準に決めただけ。だから「20℃は10℃の2倍暖かい」とは言えません。こういうデータを間隔データと呼びます。「差」は計算できますが、「2倍」は言えない。西暦も同じですよ。
🐂
ジン店長
西暦? 「2026年は1013年の2倍」って言わないもんな……確かに。
📊
豆田
西暦の0年は「時間がゼロ」ではなく、基準（紀元）を決めただけです。気温も西暦も「差は意味がある、比は意味がない」。これが間隔データの特徴です。
🐂
ジン店長
じゃあ、仕入れ2倍はどうすりゃよかったんだ……。
📊
豆田
気温の「差」を使うのが正解です。「去年の同じ週より3℃高い」と「売上の差」を比べる。比べるなら間隔データで十分に戦えます。

✏️ 途中確認 — 気温のレベル

「気温 25℃」のデータは、どのレベル（尺度）でしょう？

答えの理由
気温の0℃は「熱が無い」を意味しないので間隔尺度です。「20℃は10℃の2倍暖かい」とは言えません（−5℃も存在します）。0が本当の無かどうかで、次にやる比例と見分けます。
Scene 05 — 店のデータを総点検

「0分」は何も滞在していない——ここで差がつく

📊
豆田
さて、気温で「0の意味」が大事だとわかりました。今度は店のデータで、0が大活躍するものを探しましょう。たとえば「滞在時間」です。飲み放題120分を導入したとか?
🐂
ジン店長
おう。「滞在時間」のデータが取れるようにしたんだ。0分の客は「いなかった」ってことだろ?
📊
豆田
その通り。そして、ここが今日いちばん大事なポイントです。見てください。
📊 豆田 @mameda_ds
「0」の意味を比べてみよう。
✅ 滞在時間 0分 = まったく滞在していない
✅ 注文金額 0円 = 何も買っていない
❌ 気温 0℃ = 熱が無いわけではない
0が本当の「無」を表すデータを、比例データと呼びます。身長・金額・滞在時間はコレ。「60分は30分の2倍」と言えて、平均も自由に使える。
🐂
ジン店長
つまり……気温は「0が無じゃない」から間隔で、滞在時間は「0が無」だから比例。数字の見た目は同じ「数」なのに、中身が違うってことか。
📊
豆田
その理解で完璧です。まとめるとこうなります。
間隔データ比例データ
0の意味基準を決めただけ（0℃・西暦0年）本当の「無」（0円・0分・0cm）
例気温・西暦身長・金額・滞在時間・来店数
「差」✅ 言える✅ 言える
「2倍」❌ 言えない✅ 言える
🐂
ジン店長
滞在時間が比例なら「平均滞在時間」も出していいんだな! それで回転率を比べられる!
📊
豆田
正解。ここまで来れば、この店のデータは8割読めます。仕上げに、まとめ方の型を教えましょう。

✏️ 途中確認 — 滞在時間のレベル

「滞在時間 0分 ＝ まったく滞在していない」というデータ（滞在時間）の尺度はどれでしょう？

答えの理由
滞在時間の0分は「まったく滞在していない」という本当の無を意味します。だから比例尺度。「60分は30分の2倍」と比も言えます。0の意味で気温（間隔）と見分けるのがコツです。
Scene 06 — 総まとめ配信

4つのレベル、たった3つの質問

豆田は、店のホワイトボードに「データの4つのレベル」を書き出しました。

レベルよび方たとえばできること
1名義血液型・都道府県・会員No.分類するだけ
2順序☆レビュー・5段階評価順番をつけられる
3間隔気温（℃）・西暦差を計算できる
4比例身長・金額・時間「2倍」も言える
Level 1名義分類するだけ
Level 2順序＋ 順番をつける
Level 3間隔＋ 差を計算
Level 4比例＋ 「2倍」も言える

図1: レベルが上がるほど「できること」が増える。レベル1・2では平均できない

📊
豆田
「このデータ、どのレベル?」と迷ったら、3つの質問を順番に投げてください。1つ目「順番に意味がある?」→ なければ名義。2つ目「値と値のあいだは同じ幅?」→ 同じ幅と言えなければ順序。3つ目「0は何もない?」→ はい=比例、いいえ=間隔。
🐂
ジン店長
つまり、結論はこれか。……「平均してよいのは、数(レベル3・4)のデータだけ」。☆も会員No.も平均しちゃいけなかったんだな。
📊
豆田
そうです。レベル1・2は「いちばん多いもの」や「◯◯以上の割合」で伝える。これがデータを誠実に扱う最低ラインです。ちなみに、この炎上投稿——。

データに「会員No.（101、102、103…）」という列があります。このデータのレベルはどれでしょう？

答えの理由
会員No.は数字に見えますが、順番に意味はなく「ただの番号」。分類（名義）レベルなので、平均を出しても意味がありません。パソコン上の型ではなく「その列が何を表すか」で判断しましょう。

📝 炎上後の総決算クイズ: データの種類と尺度（6問）

正解 0 / 6問

Q1. 「東京都」「大阪府」「北海道」…のような都道府県データは名義尺度です。このデータに「平均」を出すことはできるでしょうか？

解説を見る
都道府県は名義尺度なので、四則演算は意味を持ちません。仮に「北海道=1, 青森=2, …」と番号を振って平均を出しても「都道府県コードの平均=24」と言っているだけで、何の情報にもなりません。出せるのは最頻値（最も多い都道府県）や各カテゴリの割合（例: 東京都在住が12%）です。

Q2. ネットショップのレビューで「★1〜★5」の平均が「4.2」と報告されています。★のデータはどの尺度で、この報告は厳密にはどういう問題があるでしょう？

解説を見る
★は順序尺度です。「★4と★5の差」と「★2と★3の差」が人によって同じとは限らないため、平均は厳密には不適切です。しかも平均は分布を隠します。同じ平均★4.2でも「★5ばかりの店」と「★5と★1が混在する二極化した店」では意味がまったく違います。「★4以上の割合」や中央値＋分布で報告するのが望ましいです。

Q3. 次のうち「比例尺度」のデータはどれでしょう？

解説を見る
比例尺度の0は「無」を意味します。身長0cm＝身長がない、金額0円＝何も払っていない。だから「170cmは85cmの2倍」と比が成り立ちます。一方、気温0℃は「熱がまったくない」を意味しないので間隔尺度です（-5℃も存在します）。「20℃は10℃の2倍暖かい」とは言えませんね。身長・滞在時間・来店数は比例尺度です。

Q4. データ分析の現場で「コード上は数値(int)なのに、実は名義尺度」という落とし穴があります。次のうち、その例に当てはまるのはどれでしょう？

解説を見る
郵便番号・会員ID・商品コード・電話番号は、見た目は数字ですが「足したり平均したり」する意味がありません（郵便番号の平均を出しても無意味）。滞在時間や購入金額は量を表すので平均できます。数値型かどうかではなく、その列の「意味」で尺度を判断しましょう。

Q5. 「西暦（2010年・2026年など）」のデータは、どの尺度でしょう？

解説を見る
西暦の0年は「時間がゼロ」を意味するのではなく、基準（紀元）を決めただけなので間隔尺度です。「2026年は1013年の2倍」とは言えませんね。差（何年後か）には意味があります。

Q6. アンケートで「性別」を 1＝男性・2＝女性 のように数字にコード化しました。この列の正しい扱い方はどれでしょう？

解説を見る
コード化しても意味は変わりません。1・2はただのラベル（名義尺度）なので、平均や引き算は無意味。正しくは「男性が40%、女性が60%」のように割合で集計します。
