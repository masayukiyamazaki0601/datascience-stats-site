Chapter 02 / Unit 07 — 標準化とz表

標準化とz表：正規分布の「確率」を正確に読む

このUnitでできるようになること
  • z = (x − μ) ÷ σ で標準化し、標準正規分布 N(0,1) に変換できる
  • z表（累積確率）を使って P(Z ≤ z) を読み取れる
  • 実データの「◯点以上／以下」の割合を、z表で計算できる
Step 01

標準化: どんな正規分布も「共通の物差し」に直す

Unit⑥で、正規分布は平均 μ と標準偏差 σ で決まると学びました。しかし、テストの点数（平均70・σ10）と身長（平均170cm・σ5cm）では、単位も平均もバラバラで、そのまま比べることができません。

そこで、すべての値を「平均から標準偏差いくつぶん離れているか」に変換します。これを標準化といい、変換後の値を z スコア と呼びます。

z = (x − μ) ÷ σ
  • x = μ のとき z = 0（平均ちょうど）
  • x = μ + σ のとき z = 1（平均より1σ上）
  • x = μ − 2σ のとき z = −2（平均より2σ下）

標準化した z は、平均0・標準偏差1の正規分布にしたがいます。この分布を標準正規分布 N(0, 1) と呼びます。

X ~ N(μ, σ²) を標準化 → Z = (X − μ) ÷ σ ~ N(0, 1)

なぜこんなことをするのでしょうか？理由は、μ や σ が何であっても、z さえわかれば確率が「共通の1枚の表」で読めるからです。どんな正規分布も標準化すると同じ N(0,1) になるので、あとはこの1種類について面積を計算しておけばよい、というわけです。それが次のStepのz表です。

Step 02

z表の読み方: 表の値は「z以下になる確率」

標準正規分布 N(0,1) について、左端からある z までの面積（= P(Z ≤ z)）をあらかじめ計算して表にしたものがz表（標準正規分布表）です。値の意味は「z 以下になる確率（累積確率）」です。

図1: P(Z ≤ 1.5) は「z=1.5 より左の面積」= 0.9332。右の白い部分はその残り ≈ 0.0668

代表的な z と累積確率を、表にすると次のようになります。

z0.00.51.01.52.02.53.0
P(Z ≤ z)0.50000.69150.84130.93320.97720.99380.9987

実際のz表は「行＝zの整数部と小数第1位、列＝小数第2位」の形で、z = 0.00 から 3.09 くらいまで0.01刻みで並んでいます（このコースでは主要な値だけを使います）。Pythonでは scipy.stats.norm.cdf(z) で同じ値が得られます。

✏️ 途中確認 — z表の読み方

z表で P(Z ≤ 1.0) を引くと、値はいくらになるでしょう？

答えの理由
z = 1.0 の行を引くと 0.8413。これは「平均より1σ上の位置より左に約84.1%がいる」ことを意味します。右側（z以上）は 1 − 0.8413 = 0.1587 です。
🧪 動かして確かめる — zを動かすと「左側の面積」が変わる

標準正規分布のスライダー z を動かすと、z より左の面積（＝P(Z ≤ z)）と右側の面積がリアルタイムで変わります。

Step 03

面積の計算は「引き算」と「1から引く」だけ

z表の値は「z以下（左側）」の面積でした。これを使えば、ほしい範囲の面積は次の2つのルールで計算できます。

  • 引き算: P(a ≤ Z ≤ b) = P(Z ≤ b) − P(Z ≤ a)
  • 余事象: P(Z ≥ a) = 1 − P(Z ≤ a)

例として、z が 0.5〜1.5 に入る確率を求めてみましょう。z表から P(Z ≤ 1.5) = 0.9332、P(Z ≤ 0.5) = 0.6915 です。

P(0.5 ≤ Z ≤ 1.5) = 0.9332 − 0.6915 = 0.2417

「平均より0.5σ上〜1.5σ上」の区間に、約24%のデータが入ることになります。次に、対称性を使うとマイナスの z も読めます。正規分布は左右対称なので、P(Z ≤ −1) = 1 − P(Z ≤ 1) = 1 − 0.8413 = 0.1587 です。

これを使うと、Unit⑥の68-95-99.7ルールともつながります。

P(−1 ≤ Z ≤ 1) = 0.8413 − 0.1587 = 0.6826（≈ 68%！）

✏️ 途中確認 — 上側の確率

P(Z ≥ 2) はいくらでしょう？（P(Z ≤ 2) = 0.9772 を使います）

答えの理由
「2以上」は「2以下」の残りなので、1 − 0.9772 = 0.0228 です。「〜以上」を聞かれたら余事象（1から引く）が基本です。
Step 04

実データへ: 「◯点以上」の割合を出す

それでは、平均70点・標準偏差10点のテストで実際に計算してみましょう。まず「80点以上とる人は何%いるか」を求めます。

z = (80 − 70) ÷ 10 = 1.0　→　P(Z ≥ 1) = 1 − 0.8413 = 0.1587

つまり、80点以上はおよそ16%。上位16%あたりにいる、とわかります。点数の目盛りと z の目盛りは、次の図のように対応しています。

図2: 点数の目盛りと z の目盛りは「ずらして縮めた」だけで対応する。80点は z = 1

マイナスの z も同じ手順です。「65点以下」の割合を求めると、z = (65 − 70) ÷ 10 = −0.5 なので、対称性から

P(Z ≤ −0.5) = 1 − P(Z ≤ 0.5) = 1 − 0.6915 = 0.3085

65点以下はおよそ31%です。この「まず標準化してからz表で面積を読む」という2ステップが、このUnitの中心テクニックです。

✏️ 途中確認 — 実データの割合

平均70点・標準偏差10点のテストで、「65点以下」の人はおよそ何%でしょう？

答えの理由
z = (65−70)÷10 = −0.5。P(Z ≤ −0.5) = 1 − 0.6915 = 0.3085 で約31%です。zがマイナスのときは対称性（1から引く）を使います。
Step 05

「確率から z を逆引き」する場面（パーセンタイル）

今度は逆に、「上から◯%の人は z いくつ以上か」を求めたくなる場面もあります。たとえば「上位2.5%に入るライン」を探すには、z表を逆向きに引き、P(Z ≤ z) = 0.975 となる z を探します。それが z ≈ 1.96 です。

上位2.5%の境界: P(Z ≥ z) = 0.025 ⇔ P(Z ≤ z) = 0.975　→　z ≈ 1.96

この z ≈ 1.96 は、統計学でものすごく頻繁に登場します。なぜなら、「真ん中の95%に入る範囲」は、両側に2.5%ずつ残すので、境界が z = ±1.96 になるからです。

知りたいこと対応する zよく出る場面
真ん中の 90%±1.64590%信頼区間
真ん中の 95%±1.9695%信頼区間（最も定番）
真ん中の 99%±2.57699%信頼区間

「±1.96」は第3章の信頼区間・第4章の検定で、繰り返し使うことになります。Pythonでは scipy.stats.norm.ppf(0.975) で逆引きできます。

実務上の注意も1つ。z表が使えるのは「分布が（ほぼ）正規分布だと仮定してよい」ときだけです。Unit⑥で見たように、強い右裾のデータやカウントデータにそのまま使うと、面積＝確率の前提が崩れます。まずヒストグラムなどで形を確認する習慣をつけましょう。

✏️ 途中確認 — 逆引きの定番

「真ん中の95%に入る範囲」（両側に2.5%ずつ残す）の境界となる z はおよそいくらでしょう？

答えの理由
両側に2.5%ずつ残すので、P(Z ≤ z) = 0.975 となる z ≈ 1.96 が境界です。±1.96 は95%信頼区間で必ず登場する定番の値です。
Step 06

まとめ: このUnitで身につけた道具

  • 標準化 z = (x − μ) ÷ σ：どんな正規分布も N(0,1) に変換できる
  • z表の値 = P(Z ≤ z)（z以下の左側の面積）
  • 範囲の確率は「引き算」、上側は「1から引く」、マイナスzは「対称性」
  • 実データは「標準化 → z表」の2ステップで「◯点以上」の割合が出る
  • 逆引き（パーセンタイル）では z ≈ ±1.96（真ん中95%）が最重要
z = (x − μ) ÷ σ　／　P(a ≤ Z ≤ b) = P(Z ≤ b) − P(Z ≤ a)
用語意味このUnitでの値
標準化 z スコア平均からσいくつ分かを表す値85点（μ70・σ10）→ z=1.5
標準正規分布 N(0,1)標準化した先の正規分布z表はこの分布の面積表
累積確率 P(Z ≤ z)z以下の左側の面積P(Z ≤ 1.5) = 0.9332
上側確率1 − P(Z ≤ z)P(Z ≥ 1.5) ≈ 0.067
対称性P(Z ≤ −z) = 1 − P(Z ≤ z)P(Z ≤ −0.5) = 0.3085
逆引き面積から z を求める95%中央 → ±1.96

ここまでで、正規分布にしたがう1個のデータについて「◯点以上になる確率」を計算できるようになりました。統計的推測の世界では、これが「標本平均」に対して行われます。

次はUnit⑧「中心極限定理」です。「どんな分布でも、標本平均は n が大きいほど正規分布に近づく」。そのとき平均 μ と標準偏差 σ/√n に標準化した z = (標本平均 − μ) ÷ (σ/√n) が、まさにここで学んだz表で読めるようになります。

📝 第2章ユニット⑦の確認クイズ（5問）

正解 0 / 5問

Q1. 平均60点・標準偏差5点のテストで、ある人の点数が75点でした。この人の z スコアはいくらでしょう？

解説を見る
z = (75 − 60) ÷ 5 = 15 ÷ 5 = 3 です。「平均より標準偏差3個ぶん上」の位置です。

Q2. P(Z ≤ 1.5) = 0.9332 のとき、P(Z ≥ 1.5) はおよそいくらでしょう？

解説を見る
「1.5以上」は「1.5以下」の残りなので 1 − 0.9332 = 0.0668 です。上側確率は「1から引く」が基本です。

Q3. 標準正規分布で「−2 ≤ Z ≤ 2」に入る確率はおよそいくらでしょう？（P(Z ≤ 2)=0.9772 を使います）

解説を見る
P(−2 ≤ Z ≤ 2) = 0.9772 − (1 − 0.9772) = 0.9772 − 0.0228 = 0.9544（約95%）。68-95-99.7ルールの「μ±2σ に約95%」と一致します。

Q4. 「真ん中の95%に入る範囲」の境界として、正しい z の値はどれでしょう？

解説を見る
両側に2.5%ずつ残すので P(Z ≤ z) = 0.975 となる z ≈ 1.96。この±1.96は95%信頼区間で必ず使う定番の値です。

Q5. 平均70点・標準偏差10点のテストで「90点以上」をとる人はおよそ何%でしょう？

解説を見る
z = (90 − 70) ÷ 10 = 2.0。P(Z ≥ 2) = 1 − 0.9772 = 0.0228 ≈ 2.3% です。90点は上位およそ2.3%のラインです。
