Chapter 03 / Unit 02 — 点推定と不偏推定量

点推定と不偏推定量：標本平均で母平均を「当てる」

このUnitでできるようになること
  • 「点推定」の意味と、推定量・推定値の使い分けを説明できる
  • 不偏性・一致性・有効性の意味を説明できる
  • 標本分散がなぜ「n−1」で割るのか説明できる（不偏分散）
Step 01

「母平均はいくら？」に、1つの値で答える＝点推定

Unit①で、母集団の平均 μ は通常わからず、標本平均 x̄ で推し量ると学びました。このとき「μ はおそらくこの値」と1つの値（点）で当てることを点推定と呼びます。たとえば次のような場面です。

  • ECサイトの利用者全体の平均購入額 μ を、標本平均 x̄ = 5,320円 と推定する
  • 全国の有権者の支持率 p を、標本の支持率 p̂ = 42% と推定する

ここで用語を正確に区別しておきましょう。

  • 母数（パラメータ）: 母集団の特徴を表す値（μ, σ², p など）。真の値だが不明
  • 推定量（estimator）: 母数を推定するための「計算のルール・式」（例: 標本平均 x̄ という式）
  • 推定値（estimate）: 実際の1つの標本に推定量を当てはめて得た値（例: 5,320円）

推定量は確率変数（標本が変われば値が変わる）で、推定値はその1回の実現値です。以後は、この3つを区別しながら読み進めてください。

Step 02

母数ごとの「代表的な推定量」

母数には「平均・比率・分散」などがあり、それぞれに代表的な推定量が決まっています。

母数（真の値・不明）推定量（標本から計算）備考
母平均 μ標本平均 x̄第1章でおなじみの平均
母比率 p標本比率 p̂（ハットp）「支持する人の割合」など
母分散 σ²不偏分散 s²（分母は n−1）このUnitの主役。後述
母標準偏差 σ標本標準偏差 s = √s²s² のルートをとる

「推定量」はどれも標本から計算できる式ですが、だからといって全部が良い推定量とは限りません。母数を正しく当てるには、次のStepで見るような「良い性質」が必要です。なお、第1章で学んだ「標本の分散を n−1 で割る」理由は、まさにこの「良い推定量」の話です（Step04で解決します）。

✏️ 途中確認 — 点推定

母平均 μ を点推定したいとき、推定量として使うのはどれでしょう？

答えの理由
母平均 μ の点推定には標本平均 x̄ を使うのが基本です（不偏性・一致性を持つ）。イの中央値も平均の代わりに使う場面はありますが、このUnitで扱うのは平均の推定です。
Step 03

良い推定量の3つの性質（不偏性・一致性・有効性）

推定量は標本ごとにブレる確率変数です。では、どんな推定量が「良い」のでしょうか？代表的な3つの性質があります。

  • 不偏性（unbiasedness）: 推定量の期待値が母数に一致する。E(x̄) = μ
  • 一致性（consistency）: 標本サイズ n を大きくすると、推定量が母数に近づいていく
  • 有効性（efficiency）: 同じ条件の推定量の中では「ばらつき（分散）」が小さい方がよい

ダーツに例えると、「狙う的＝母数 μ」に対して、推定量（矢）が次のようだと言えます。

  • 不偏性 = 矢の「当たりどころの中心」が的に合っている（偏りなし）
  • 有効性 = 矢の散らばり（ブレ）が小さい

図1: 各標本の x̄ は μ（中心）のまわりに散らばる。中心が μ に一致＝不偏性。散らばりの小ささ＝有効性

標本平均 x̄ は、これら3つをすべて満たす代表的な推定量です（不偏性 E(x̄)=μ は第2章Unit⑧で確認済み。一致性は中心極限定理の帰結。有効性も成立します）。

✏️ 途中確認 — 不偏性

推定量の性質「E(推定量) = 母数 が成り立つこと」を何と呼ぶでしょう？

答えの理由
期待値が母数に一致するのが「不偏性」です。n を大きくすると母数に近づくのが一致性、散らばりが小さいのが有効性です。
Step 04

なぜ分散は「n−1」で割るのか（不偏分散の謎）

第1章で、標本の分散を計算するときは n ではなく n−1 で割ると学びました。ここでその理由を解決します。結論から言うと、「n で割る標本分散」は母分散 σ² の不偏推定量にならないからです。

理由は次の通り。母平均 μ がわかっていれば、各データのズレは μ から測れます。しかし現実には μ がわからないので、標本平均 x̄ から測ります。x̄ はデータの中心に必ず「くっついて」いるため、x̄ からのズレ2乗の合計は、μ からのズレ2乗の合計より平均的に小さくなります。その分を補正するのが n−1 です。

s²（不偏分散） = Σ(xᵢ − x̄)² ÷ (n − 1)　→　E(s²) = σ²（不偏！）

n = 10、母分散 σ² = 2 の例で「標本分散の平均」を比べると、次のようになります。

図2: n=10・母分散σ²=2 のとき。÷n の標本分散は平均的に (n−1)/n×σ² = 1.8 にしかならない。÷(n−1) なら平均的に σ²=2 に一致

「自由度」という言葉で説明されることもあります。標本平均 x̄ を1つ計算してしまうと、n 個のデータのうち自由に動けるのは n−1 個だけ（最後の1個は x̄ と合計から自動的に決まる）だから、n−1 で割る、という理屈です。

✏️ 途中確認 — n−1の理由

標本の分散を計算するとき、n ではなく n−1 で割る主な理由はどれでしょう？

答えの理由
x̄ はデータの中心に寄るため、x̄ からの2乗和は μ からの2乗和より平均的に小さくなります。n−1 で割ることで、その分を補正して母分散 σ² の不偏推定量にします。
Step 05

実務ではどう計算する？Python（pandas / NumPy）

データサイエンスの現場では、pandas や NumPy を使うのが普通です。実は、pandas の var() はデフォルトで分母 n−1（不偏分散）です。NumPy はデフォルトが n で割るので、ddof=1 を指定して不偏分散にします。

# 例: 5人のデータ [4, 7, 10, 13, 16]（平均10、2乗和90）
import pandas as pd
import numpy as np
x = pd.Series([4, 7, 10, 13, 16])

x.var()          # 90 ÷ (5−1) = 22.5（不偏分散）
np.var(x, ddof=1)  # 同じく 22.5
np.var(x)         # 90 ÷ 5 = 18.0（nで割る＝平均的に小さめ）

データ分析で「分散」「標準偏差」と書いたときは、暗黙に不偏版（n−1）を使うことがほとんどです。推定や検定（次Unit以降）でも、不偏分散 s² をそのまま使います。

✏️ 途中確認 — pandasの分散

pandas の Series.var()（引数なし）は、分母をどうするでしょう？

答えの理由
pandas の var() はデフォルトで不偏分散（分母 n−1）です。NumPy の np.var() は n で割るので、不偏分散が欲しいときは ddof=1 を指定します。

最後に、「不偏」の意味をシミュレーションで体感しましょう。母集団は値0,1,2,3を確率40%,30%,20%,10%で出す分布（母平均 μ=1、母分散 σ²=2）。ここから標本を何度もとって、毎回「標本平均」「分散÷n」「不偏分散÷(n−1)」を計算し、それぞれの「平均」を見ます。

🧪 動かして確かめる — 不偏推定量は「平均すると母数に一致」

標本ごとの x̄・÷nの分散・÷(n−1)の分散を記録し、それらの平均がどこへ収束するかを見ます。÷n の分散は平均的に母分散を過小評価し、÷(n−1) は母分散に一致するはずです。

Step 06

まとめ: このUnitで身につけた道具

  • 点推定 = 母数を1つの値で当てる。推定量（式）と推定値（実測）を区別する
  • 代表的な対応：μ→x̄、p→p̂、σ²→不偏分散 s²、σ→s
  • 良い推定量の3条件：不偏性・一致性・有効性。x̄ はすべて満たす
  • 分散は n−1 で割る（÷n は平均的に過小評価 → 不偏にならない）
  • 実務では pandas の var()（分母 n−1）／NumPy は ddof=1
E(x̄) = μ　／　s² = Σ(xᵢ − x̄)² ÷ (n − 1)、E(s²) = σ²
用語意味例
点推定母数を1つの値で当てることμ ≈ 5,320円
母数（パラメータ）母集団の特徴量（未知の真値）μ, σ², p
推定量 / 推定値推定の式 / その実現値x̄（式）/ x̄=5,320円
不偏性E(推定量) = 母数E(x̄) = μ
一致性 / 有効性n大で母数へ / 分散が小さいx̄ は両方満たす
不偏分散 s²分母 n−1 の標本分散E(s²) = σ²

点推定は「1つの値」を出しますが、その値が母数からどれくらいズレているか（誤差の範囲）は教えてくれません。そこを扱うのが、次のUnit③「標本平均の分布と標準誤差」とUnit④以降の区間推定（信頼区間）です。

次はUnit③「標本平均の分布と標準誤差」で、x̄ の分布（中心極限定理）を「推定の道具」として使いこなす復習と整理をします。

正解 0 / 5問

Q1. 「点推定」とは、どのような推定の仕方でしょう？

解説を見る
点推定は「μ はおおよそ 5,320円」のように母数を1つの値（点）で当てます。範囲で答えるのは区間推定（次Unit以降）です。

Q2. 標本平均 x̄ が持つ「E(x̄) = μ」という性質を何と呼ぶでしょう？

解説を見る
期待値が母数 μ に一致する性質を不偏性と呼びます。x̄ は不偏性に加えて一致性・有効性も満たす、代表的な推定量です。

Q3. 標本の分散を計算するとき、n ではなく n−1 で割る理由として正しいものはどれでしょう？

解説を見る
x̄はデータの中心に寄るので、x̄からの2乗和は母平均μから測ったときより平均的に小さくなります。n−1で割って補正した不偏分散s²が、母分散σ²の不偏推定量になります。

Q4. 母分散 σ² = 20 の母集団から n = 11 の標本を何度もとって「÷n の標本分散」を計算しました。その平均はおよそいくらになるでしょう？

解説を見る
÷n の標本分散の平均は (n−1)/n × σ² = 10/11 × 20 ≈ 18.18 です。nで割る分散は平均的に母分散を過小評価します。

Q5. pandas の DataFrame/Series の var()（引数なし）について正しいものはどれでしょう？

解説を見る
pandas の var() はデフォルトで不偏分散（分母 n−1）です。NumPy の np.var() は n で割るので、ddof=1 を指定して揃えます。
