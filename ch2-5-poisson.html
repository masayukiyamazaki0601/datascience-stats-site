Chapter 02 / Unit 05 — ポアソン分布

ポアソン分布：めったに起きないことの「回数」を扱う

このUnitでできるようになること
  • ポアソン分布が使える場面（まれな事象の回数）を説明できる
  • P(X = k) = e^(−λ) × λ^k ÷ k! で確率を計算できる
  • 期待値も分散も λ になることと、λ で形が変わることを説明できる
Step 01

「まれなこと」が、ある期間に何回起きるか

前のUnit④で「成功回数の分布」＝二項分布を学びました。ところが現実には、次のようなデータもあります。

  • コールセンターに、1時間に平均2件の問い合わせが来る
  • 1日に平均1.5件のシステム障害が起きる
  • 1ページの本に平均0.5個の誤植がある
  • 1年間に平均3件の重大事故が起きる

共通しているのは、「ある期間（または範囲）に、めったにないことが何回起きるか」を数えたい、という点です。これを二項分布で無理やり扱おうとすると、問題があります。

「1時間に平均2件」を二項分布で考えるには、「何回の試行なのか」を決めなければいけません。時間は連続なので、そもそも n が決まりません。無理に「1秒ごとの試行」とすれば n = 3,600 という巨大な数になり、1秒あたりの発生確率 p = 2/3,600 は極めて小さくなります。つまり「n がとても大きく、p がとても小さい二項分布」です。

このような極限で二項分布が近づいていく先の分布が、このUnitのテーマポアソン分布です。ポアソン分布なら「平均 λ 回」だけで、試行回数 n を考えずに確率を出せます。

このUnitの進め方です。

  1. 公式とパラメータ λ を覚える
  2. λ で「形」がどう変わるかを見る
  3. 具体的な計算（コールセンターの例）を練習する
  4. 二項分布との使い分けを整理する
Step 02

公式: P(X = k) = e^(−λ) × λ^k ÷ k!

「単位時間あたり平均 λ 回起きる」まれな事象について、その期間にちょうど k 回起きる確率を X と書くと、X の確率は次の式で与えられます。

P(X = k) = (e^(−λ) × λ^k) ÷ k!　　（k = 0, 1, 2, …）

ここで λ（ラムダ）は「1期間あたりの平均発生回数」です。例えば「1時間に平均2件」なら λ = 2 です。e は「ネイピア数」と呼ばれる定数で、およそ 2.718 です。電卓やPython（scipy）では関数が用意されているので、手計算では e^(−λ) の値を表から見るのが普通です。

e ≈ 2.71828…　／　λ = 平均発生回数
式の読み方 — むずかしく考えないで

この式は「ちょうど k 回起きる確率」を出すためのものです。パーツは3つあります。

  • e^(−λ) … 計算の基準になる値。実は「1回も起きない確率」です（k = 0 のとき、式は e^(−λ) だけになります）。
  • λ^k … 平均 λ を k 回かけたもの。「λ^2 = λ × λ」「λ^3 = λ × λ × λ」のこと。
  • k! … 1 から k まで順番にかけたもの（「階乗」と読みます）。2! = 2×1、3! = 3×2×1 のこと。

つまり (e^(−λ) × λ^k) ÷ k! に、k = 0, 1, 2, … を1つずつ入れていくだけです。次のStep04で、実際に数字を当てはめて確かめます。

二項分布のパラメータは n と p の2つでしたが、ポアソン分布は λ だけで分布の形がすべて決まります。n や p をいちいち考えなくてよいのが、この分布の便利なところです。

ポアソン分布がうまく当てはまるのは、だいたい次の3つの条件が成り立つときです。

  • 平均の発生率 λ が期間中だいたい一定
  • ある瞬間に起きることと、次の瞬間に起きることは独立
  • 同時に2回以上起きることは無視できるほどまれ

※ 式の細かい導出（二項分布からどう近づくか）は、このUnitでは省略します。「n を無限大、p を0に近づけ、n×p を λ に固定したときに二項分布がたどり着く先」くらいのイメージで大丈夫です。

Step 03

λ が小さいと「0回」が最頻、大きいと山が右へ動く

ポアソン分布の形は、λ の値1つで決まります。λ が小さい＝「とてもまれ」なので、0回が最も起こりやすく、回数が増えるほど確率が下がります。λ が大きくなるにつれ、山（最頻値）は右へ移動し、左右対称に近づいていきます。2つの例を比べてみましょう。

図1: ポアソン分布の形は λ で決まる。λ=0.5 なら0回が最頻、λ=5 なら山が右（平均のあたり）へ移動（高さは各パネル内で正規化）

λ が大きくなると山が左右対称の釣り鐘型に近づいていくのは、二項分布が正規分布に近づくのと同じ流れです（次々回のUnit⑥・⑧で扱います）。

そして、ポアソン分布の期待値は λ そのものです。さらに驚くべきことに、分散も λ になります。つまり「平均もバラつきも λ」で、1つの値 λ が分布の位置と広がりを同時に決めます。

E(X) = λ　／　V(X) = λ　／　σ(X) = √λ

✏️ 途中確認 — λ が小さいポアソン分布の形

λ = 0.5 のように平均がとても小さいポアソン分布の形はどれでしょう？

答えの理由
λ が小さい＝「とてもまれ」なので、0回がいちばん起こりやすく、1回、2回…と増えるほど確率は下がっていきます。山が右へ動くのは λ が大きくなったときです。
Step 04

計算例: 1時間に平均2件の問い合わせ（λ = 2）

コールセンターで、1時間に平均 λ = 2件 の問い合わせがあるとします。このとき「1時間にちょうど k 件」の確率を、公式から求めます。

まず k = 0（1件も来ない）から計算します。k = 0 のときは、λ^0 = 1、0! = 1 という約束なので、式の「× λ^k ÷ k!」の部分が 1 ÷ 1 = 1 になり、式は e^(−λ) だけに変わります。

P(X = 0) = e^(−2) ≈ 0.135（1時間、1件も来ない確率）

これが基準の値になりました。ここから先は、この 0.135 を使って次々に計算していきます。

k = 0, 1, 2, … と順に計算して表にすると、次のようになります。

問い合わせ件数 k0123456
P(X = k)0.1350.2710.2710.1800.0900.0360.012

図2: λ=2 のポアソン分布。1件・2件が最も多く、右へなだらかに下がる（7件以上はほぼ0）

✏️ 途中確認 — ポアソン分布の計算①

λ = 2 のとき、「1時間に1件も問い合わせが来ない」確率 P(X = 0) はおよそいくらでしょう？

答えの理由
P(X=0) = e^(−2) ≈ 0.135 です。ウの0.368は λ=1 のときの P(X=0) = e^(−1) なので、λ の値に注意しましょう。

続いて「3件以上の問い合わせが来る確率」も出してみましょう。その前に、k = 1, 2, 3 の確率を、式に数字を当てはめて計算します。

P(X = 1) = e^(−2) × 2^1 ÷ 1!　=　0.135 × 2 ÷ 1　≈ 0.271
P(X = 2) = e^(−2) × 2^2 ÷ 2!　=　0.135 × 4 ÷ 2　≈ 0.271
P(X = 3) = e^(−2) × 2^3 ÷ 3!　=　0.135 × 8 ÷ 6　≈ 0.180

〈計算の読み方〉 λ^k は「λ を k 回かける」ので、2^3 = 2×2×2 = 8。k! は「1から順にかける」ので、3! = 3×2×1 = 6。e^(−2) ≈ 0.135 は k に関係なくいつも同じ値です。

この並びを見ると、1つのコツに気づきます。P(X=1) は P(X=0) の 0.135 × 2、P(X=2) は 0.271 × 1、P(X=3) は 0.271 × (2÷3)……つまり「1つ前の答え × λ ÷ k」で次々に計算できます（表の 0.090、0.036… も同じくり返しです）。

「0件〜2件」をまとめると 0.135 ＋ 0.271 ＋ 0.271 ≈ 0.677 なので、その残りが「3件以上」です。

P(X ≤ 2) ≈ 0.677　／　P(X ≥ 3) = 1 − 0.677 ≈ 0.323

✏️ 途中確認 — ポアソン分布の計算②

λ = 2 のとき、「1時間に3件以上の問い合わせが来る」確率 P(X ≥ 3) はおよそいくらでしょう？

答えの理由
P(X ≥ 3) = 1 − P(X ≤ 2) = 1 − 0.677 ≈ 0.323 です。「〜以上」は余事象（1から引く）で出すのが早いです。アは P(X ≤ 2) なので、問いの向きが逆です。

この計算がなぜ実務で役立つかというと、「平均2件」と言われても、実際には3件以上来る時間帯が3割以上あることがわかるからです。

コールセンターの人員配置や、サーバーの処理能力設計では、「平均」だけでなく「まれに大きくなる側（右のすそ）」を見る必要があります。ポアソン分布は、この「まれに大きくなる」部分をちゃんと評価できる道具です。

Step 05

二項分布とどう使い分ける？実務での使われ方

「コインを10回」のような「回数が決まっている試行」は二項分布、「1時間・1日・1ページ」のような区切りがない連続した範囲での発生回数はポアソン分布、が基本の使い分けです。表にまとめると次のようになります。

二項分布 Bin(n, p)ポアソン分布 Po(λ)
考えるものn回の試行のうち成功した回数期間・範囲に発生する回数
パラメータn（回数）と p（成功確率）λ（平均発生回数）
例コイン10回の表の回数、10人に送って開封した人数1時間の問い合わせ件数、1日の事故件数
期待値 / 分散E = n×p ／ V = n×p×(1−p)E = λ ／ V = λ

そして、二項分布とポアソン分布は別物ではなく、「n を大きく、p を小さくした二項分布 ≈ ポアソン分布（λ = n×p）」という関係があります。

例えば「来場者10,000人のうち0.1%が購入する」のような極端にまれな事象は、n = 10,000 の二項分布として計算するより、λ = 10 のポアソン分布として扱う方が楽で、答えもほぼ同じになります。

実務では、発生件数（カウントデータ）を説明・予測する「ポアソン回帰」というモデルもあります。売上件数・事故件数・サイトへのアクセス数など、「0以上の整数で、まれに大きくなる」データの分析に使われます（このコースの後の回帰の章で触れます）。

✏️ 途中確認 — 期待値も分散も λ

λ = 2 のポアソン分布について、正しいのはどれでしょう？

答えの理由
ポアソン分布は E(X) = λ、V(X) = λ です。λ=2 なら期待値も分散も2。標準偏差は σ = √2 ≈ 1.41です。パラメータが1つだけで両方が決まるのが特徴です。
Step 06

まとめ: このUnitで身につけた道具

  • ポアソン分布 = 「期間・範囲に、まれなことが何回起きるか」の分布（例: 1時間の問い合わせ件数）
  • P(X = k) = e^(−λ) × λ^k ÷ k!（λ が分布を決める唯一のパラメータ）
  • 期待値も分散も λ（σ = √λ）
  • λ が小さいと 0回 が最頻、λ が大きくなると山が右へ動き、左右対称に近づく
  • 二項分布（n大・p小）の極限がポアソン分布。区切りのない「発生件数」データではポアソンを使う
P(X = k) = e^(−λ) × λ^k ÷ k!　／　E(X) = λ　／　V(X) = λ
用語意味このUnitでの例
発生回数 X期間・範囲に起きる回数（0,1,2,…）1時間の問い合わせ件数 X
λ（ラムダ）1期間あたりの平均発生回数λ = 2件／時間
e（ネイピア数）公式に出てくる定数 ≈ 2.718e^(−2) ≈ 0.135
ポアソン分布 Po(λ)まれな事象の回数がしたがう分布コールセンターの例
期待値 / 分散どちらも λλ=2 → 平均2件・分散2

ここまでで「数える（カウント）データの分布」は一通りそろいました。二項分布・ポアソン分布は、いずれも離散型（0,1,2,…と飛び飛びの値）の分布です。

次はUnit⑥「正規分布」です。身長・テストの点数・測定誤差のような連続型（どこまでも細かい値をとる）データの代表的な分布で、統計学の主役とも言える分布を扱います。

📝 第2章ユニット⑤の確認クイズ（5問）

正解 0 / 5問

Q1. 次のうち、ポアソン分布でモデル化するのがふさわしいものはどれでしょう？

解説を見る
ポアソン分布は「期間・範囲にまれなことが何回起きるか」（カウントデータ）に使います。イは回数が決まった試行なので二項分布、エは連続型なので正規分布の方がふさわしいです。

Q2. λ = 3 のポアソン分布の期待値 E(X) はいくらでしょう？

解説を見る
ポアソン分布の期待値は λ です。λ=3 なら E(X)=3。ちなみに分散も3、標準偏差は σ = √3 ≈ 1.73 になります。

Q3. λ = 1 のとき、「その期間に1回も起きない」確率 P(X = 0) はおよそいくらでしょう？

解説を見る
P(X=0) = e^(−1) ≈ 0.368 です。λ=2 のときは e^(−2) ≈ 0.135 になるので、λ の値を確認しましょう。

Q4. λ = 5 のポアソン分布の標準偏差 σ(X) はおよそいくらでしょう？

解説を見る
分散が λ=5 なので、標準偏差は σ = √λ = √5 ≈ 2.24 です。エの√2 ≈ 1.41は λ=2 のときの値です。

Q5. 二項分布 Bin(n, p) とポアソン分布の関係として正しいものはどれでしょう？

解説を見る
「回数 n が巨大・成功確率 p が極小」というまれな事象の極限で、二項分布は平均 λ = n×p のポアソン分布に近づきます。これが「1時間」のような区切りのない問題でポアソンが使える理由です。
