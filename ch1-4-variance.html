分散と標準偏差

このUnitでできるようになること
  • 「平均からのズレ」を使って散らばりを測る考え方を説明できる
  • 分散・標準偏差をステップ計算できる
  • 「n−1で割る理由」をなんとなくではなく説明できる
Step 01

平均8分の2軒の店、どちらが「待ち時間が読める」？

あなたはカフェ巡りが趣味。2軒のカフェに「待ち時間」を5回ずつ測ってもらいました。どちらも平均8分です。

カフェA（繁華街） 平均8分
平均8分
30分待ち
0分 10分 20分 30分
カフェB（住宅街） 平均8分
平均8分
0分 10分 20分 30分

図1: 平均はどちらも8分（破線）。でもAは30分待ちが飛び出し、Bは8分のまわりに集中している

カフェAは、空いているとき（1〜4分）と大行列のとき（30分）で待ち時間が読めません。カフェBはいつ行っても8分前後。でも「平均8分」とだけ聞くと、この差は伝わりません。

このUnitでは、この「散らばり」を1つの数字で表す方法を学びます。それが分散と標準偏差です。

✏️ 途中確認 — なぜ散らばりを測る？

「いつ行っても待ち時間が読める（安定している）」のはどちらのカフェでしょう？

答えの理由
カフェBは7〜9分に固まっているので、待ち時間を予想しやすい。平均が同じでも「散らばり」で性質の差がわかります。
Step 02

散らばり = 「平均からどれだけ離れているか」

散らばりを測る自然な方法は、「各データが平均からどれだけ離れているか」を足し合わせることです。この「離れ具合」を偏差と呼びます。

計算しやすい身長データ（160, 165, 170, 175, 180cm・平均170cm）で試してみましょう。

身長平均偏差（身長−平均）
160170−10
165170−5
1701700
175170＋5
180170＋10

この偏差を全部足してみると… −10 + (−5) + 0 + 5 + 10 = 0。いつも0になってしまい、役に立ちません。プラスとマイナスが打ち消し合うからです。

そこで登場するのが「2乗」です。2乗すれば全部プラスになり、打ち消し合いません。

(−10)² + (−5)² + 0² + 5² + 10² = 100 + 25 + 0 + 25 + 100 = 250

✏️ 途中確認 — 偏差の性質

偏差（データ − 平均）を全部足すと、いつもどうなるでしょう？

答えの理由
プラスの偏差とマイナスの偏差が必ず打ち消し合うので、合計はいつも0。だから2乗して全部プラスにしてから足し合わせます。

✏️ ここでひと休み — なぜ2乗する？

偏差を2乗してから足し合わせる目的はどれでしょう？

答えの理由
(−10)² も 10² も 100 になるように、2乗すればマイナスもプラスになります。偏差の合計がいつも0になる問題を回避して、「散らばりの大きさ」を足し合わせられるようにするためです。
Step 03

分散 = 「偏差の2乗の平均」

「2乗した偏差（100, 25, 0, 25, 100）を平均する」のが分散です。平均を取るときに、なぜ「n−1」で割るかはStep 05で説明します。いったん数字で見てください。

分散 = (100 + 25 + 0 + 25 + 100) ÷ (5 − 1) = 250 ÷ 4 = 62.5

「ふつうの平均なら250÷5=50じゃない？」と思うかもしれませんが、データ分析ではn−1で割るのが標準です（理由はこのUnitの最後で）。

✏️ 途中確認 — 分散の計算

身長データの「偏差の2乗の合計」はいくらでしたか？

答えの理由
(−10)² + (−5)² + 0² + 5² + 10² = 100+25+0+25+100 = 250。これを n−1 = 4 で割ると分散 62.5 です。
Step 04

標準偏差 = √分散。「平均からだいたい±何cm」

分散62.5の単位は「cm²」。2乗したぶん、単位が変わってしまってイメージしにくいです。そこで平方根を取ったのが標準偏差です。

標準偏差 = √62.5 ≒ 7.9cm

これで「この5人は、平均170cmからだいたい±7.9cmのあたりに散らばっている」と読めます。

✏️ ここでひと休み — 標準偏差の読み方

「標準偏差 7.9cm」の読み方として正しいのはどれでしょう？

答えの理由
標準偏差は「平均からだいたいどれくらい散らばっているか」の目安。単位も「cm」に戻るので、「170cm ± 7.9cm あたりに収まる」とイメージできます。いちばん高い人と低い人の差（=20cm）とは別物です。
平均 170cm

図2: 5人の身長（160〜180cm）。平均170cmのまわりに、だいたい±7.9cmで収まっている

✏️ 途中確認 — 標準偏差の計算

分散 62.5 の平方根（標準偏差）はおよそいくらでしょう？

答えの理由
√62.5 ≒ 7.9。√（平方根）を取ることで、単位がcm²からcmに戻り、「平均からだいたい±7.9cm」と読めるようになります。
Step 05

2軒のカフェを標準偏差で比べる

標準偏差の計算方法がわかったので、最初のカフェの話に戻りましょう。標準偏差（n−1方式）を計算すると、次のようになります。

カフェ待ち時間平均標準偏差
A（繁華街）1, 2, 3, 4, 30分8分約 12.3分（30分の行列に引っ張られる）
B（住宅街）7, 8, 8, 8, 9分8分約 0.7分（ほぼ毎回8分前後）

「平均は8分」だけでは同じに見えた2軒が、「標準偏差は12.3分と0.7分」と聞けば、待ち時間の当てやすさがまったく違うと伝わります。

✏️ 途中確認 — 標準偏差の読み方

「いつ行っても待ち時間が安定している」のは、標準偏差がどちらのカフェでしょう？

答えの理由
標準偏差が小さい＝平均のまわりに集まっている＝予想しやすい。Bは約0.7分。Aは30分の外れ値のせいで約12.3分まで大きくなっています。

もう1つ、実務でよくある具体例を見ましょう。ネジ工場で「長さ5.00mmの部品」を作っています。お客様との約束（公差）は 4.95〜5.05mm。これを外したら不良品です。

工程A σ=0.02
工程B σ=0.08

図4: 平均はどちらも5.00mm。でもσの大きい工程Bは公差（帯の内側）から外れて不良になる（赤い点）

平均が同じ5.00mmでも、標準偏差が小さい工程Aなら不良が起きにくく、大きい工程Bでは不良が出てしまう。工場では「平均を合わせる」だけでなく「ばらつき（σ）を小さくする」ことが品質の命です。標準偏差は品質管理でも当たり前に使われています。

✏️ 途中確認 — 実務での使い方

公差 4.95〜5.05mm の部品を安定して作るためには、どの工程を採用するのがよいでしょう？

答えの理由
平均が同じでもσが大きいと公差の外に出る（不良になる）データが生まれます。ばらつきを小さく保つことが品質管理の基本です。
Step 06

便利な目安: 68-95-99.7ルール

データが「左右対称の山型」の場合、平均と標準偏差から「データがどの範囲に何%入るか」の目安がわかります。

図3: 山型（正規分布）のカーブ。平均±1σに約68%（濃い帯）、±2σに約95%、±3σに約99.7%（薄い帯）

注意: 使えるのは「左右対称の山型」のときだけ

年収のように右に裾の長いデータでは、この目安は当てはまりません。形を確認せずに「±2σ=95%」と使うのは危険です。データの「形」の見方は次のUnit（ユニット⑤）で学びます。

✏️ 途中確認 — 68-95-99.7ルール

左右対称の山型データでは、平均±標準偏差（±1σ）の範囲に、およそ何%のデータが入るでしょう？

答えの理由
±1σ＝約68%、±2σ＝約95%、±3σ＝約99.7%。ただし左右対称の山型のときだけ。この目安は第2章の「正規分布」で再登場します。

✏️ ここでひと休み — 95%の目安

左右対称の山型データで、平均±2σ（標準偏差の2倍）の範囲に入るのは、およそ何%でしょう？

答えの理由
±1σ=約68%・±2σ=約95%・±3σ=約99.7%。たとえばネジ工場なら「公差が±2σに入るか」が品質管理の目安になります。※年収のように歪んだデータでは使えないので注意。
Step 07

おまけ: なぜ「n−1」で割るの？

データ分析の目的は、たいてい「手元のサンプルから、全体（母集団）のことを知る」ことです。サンプルの散らばりは全体より少し小さくなりがちなので、nで割ると母集団の分散を過小評価してしまいます。n−1で割ると、ちょうどよい補正になるのです。

実務のツールも、この「n−1方式」が標準です。

ツール書き方
NumPynp.var(x, ddof=1) / np.std(x, ddof=1)
pandasdf.var() / df.std() は最初からn−1方式

✏️ ここでひと休み — 実務ツールの標準

データ分析の標準（n−1方式）が「最初から」採用されているのはどれでしょう？

答えの理由
pandas の var()/std() は最初から分母 n−1 の不偏版です。NumPy は np.var(x, ddof=1) のように指定しないと n で割ります（第3章の推定で大事になる話です）。
Pythonで確かめたい人向け（任意） 
import numpy as np
heights = np.array([160, 165, 170, 175, 180])
print(np.var(heights, ddof=1))  # 62.5（n−1方式・データ分析の標準）
print(np.std(heights, ddof=1))  # 約7.9
print(np.var(heights))          # 50.0（n方式＝そのデータ自体の散らばり）

✏️ 途中確認 — n−1の理由

サンプルの分散を n で割るとどうなりがちでしょう？

答えの理由
サンプルは全体より偏りがちで、散らばりが小さく出やすい。n−1で割って補正しないと、母集団の分散を過小評価してしまいます。

正解 0 / 4問

Q1. 身長データ 160, 165, 170, 175, 180（cm）の「標準偏差」（n−1で割る方式）はおよそいくらでしょう？

解説を見る
平均170cm。偏差の2乗の合計は 100+25+0+25+100=250。不偏分散 = 250÷(5−1) = 62.5、標準偏差 = √62.5 ≒ 7.9cm です。

Q2. 上のデータの「分散 = 62.5」の単位は何でしょう？

解説を見る
偏差（cm）を2乗して足したので単位は cm² になります。そのため最後に平方根を取って標準偏差（cm）に戻して使うのが一般的です。

Q3. 不偏分散では n で割らず「n−1」で割ります。その理由として正しいのはどれでしょう？

解説を見る
サンプルのばらつきは母集団のばらつきより小さくなりがちで、n で割ると母分散を平均的に過小評価します。n−1 で割ることで偏りなく推定できます。

Q4. データ [8, 8, 8, 8] の標準偏差はいくらでしょう？

解説を見る
すべての値が平均(8)と同じなので、偏差は全部0。標準偏差は0になります。全データが同じ値のときだけ標準偏差は0です。
