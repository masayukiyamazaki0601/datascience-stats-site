分散と標準偏差

Step 01

1.5 どのくらい散らばっている？その2: 分散と標準偏差

四分位数は「並べたときの位置」で散らばりを測りました。一方の標準偏差は「平均から平均的にどれだけ離れているか」で散らばりを測ります。機械学習でも「特徴量のスケール」の話で必ず登場するので、計算の意味まで理解しておきましょう。

1.5.1 具体例: 平均8分でも、お店の性質はまるで違う

2軒のカフェの「待ち時間（分）」を1日5回観測したデータです。

お店待ち時間の記録（分）平均読み取り
カフェA（繁華街）1, 2, 3, 4, 308分空いているときも激混みのときもあり、待ち時間が読めない
カフェB（住宅街）7, 8, 8, 8, 98分いつ行っても安定して8分前後

平均はどちらも8分。でも「いつ行っても安心」なのは明らかにBです。Aは30分待ちという外れ値（たまたま昼休みの行列にぶつかった記録）が含まれています。標準偏差はこの差を数字で表してくれます（後ほど計算すると A ≈ 12.3分、B ≈ 0.7分）。

1.5.2 身長データ（例B）で分散をステップ計算する

数字がきれいな例B（5人の身長: 160, 165, 170, 175, 180 cm）で、地道に1ステップずつ計算します。

STEP1: 平均を出す

\[ \bar{x} = \frac{160+165+170+175+180}{5} = \frac{850}{5} = 170 \ \text{cm} \]

STEP2: 各データの「平均からのズレ（偏差）」とその2乗を計算する

身長 \(x_i\)平均偏差 \(x_i - \bar{x}\)偏差の2乗 \((x_i-\bar{x})^2\)
160170−10100
165170−525
17017000
175170+525
180170+10100
2乗の合計250

STEP3: 2乗の平均を取る（これが分散）

\[ s^2 = \frac{100+25+0+25+100}{5-1} = \frac{250}{4} = 62.5 \ \text{cm}^2 \]

STEP4: 平方根を取る（これが標準偏差）

\[ s = \sqrt{62.5} \approx 7.9 \ \text{cm} \]

つまり「この5人の身長は、平均170cmからだいたい ±7.9cm のあたりに散らばっている」と読めます。

なぜ STEP2 で「2乗」するのか？ もし2乗せずに偏差をそのまま足すと、−10 +(−5) + 0 + 5 + 10 = 0 になり、常にゼロで役に立ちません。2乗して正の値にすることで「平均からの距離」として足し合わせられるのです。 そして2乗したぶん単位が cm² に変わってしまうので、最後に平方根を取って単位を cm に戻したものが標準偏差です。

1.5.3 標準偏差の「だいたい」の解釈

データが「山型で左右対称に近い分布」のとき、経験則として次のことが成り立ちます（この性質は第2章の正規分布で再登場します）。

  • 平均 ± 標準偏差 の範囲に、だいたい 全体の約68% が入る
  • 平均 ± 2×標準偏差 の範囲に、だいたい 全体の約95% が入る
  • 平均 ± 3×標準偏差 の範囲に、だいたい 全体の約99.7% が入る
「平均±2σ = 全体の95%」が使える条件 これは分布が左右対称の山型（正規分布に近い）場合の経験則です。年収のような右に裾の長いデータには当てはまりません。データの形を確認せずに「95%」を使うのは誤解のもと。形の確認方法は次の1.6で扱います。

1.5.4 なぜ「n−1」で割るのか？（第3章の先取り）

上の計算は n−1 = 4 で割りました。データそのものの散らばりを知りたいだけなら n=5 で割ればいいのですが、データ分析の実務では「手元のサンプルから母集団全体の分散を推定する」のが目的です。サンプルから推定する場合、n で割ると平均して過小評価してしまうことが知られており、n−1 で割ることで偏りがなくなる（不偏になる）ため、n−1 が標準になっています。

  • NumPy: np.var(x, ddof=1), np.std(x, ddof=1)
  • pandas: df.var(), df.std() はデフォルトで n−1 方式
  • 「母分散が既知の完全データ」を扱うときだけ n で割る（統計検定などの問題ではこちらも出る）
import numpy as np
heights = np.array([160, 165, 170, 175, 180])
print(np.var(heights, ddof=1))   # 不偏分散: 62.5
print(np.std(heights, ddof=1))   # 標準偏差: 7.905...
# 例A（EC注文金額）だと外れ値8900円の影響で標準偏差は約2508円にもなる
orders = np.array([640, 760, 850, 980, 1200, 1200,
                   1500, 2100, 3400, 8900])
print(np.std(orders, ddof=1))   # 2508.34（標準偏差も外れ値に敏感）
まとめ: ばらつき指標の使い分け
指標外れ値の影響おすすめ場面
範囲（レンジ）非常に敏感概要をぱっと見るだけ
IQR（四分位範囲）ほぼ受けない中央値とセットで頑健な要約をしたいとき
標準偏差敏感（2乗するため）平均とセットで使うとき。機械学習の特徴量スケーリングでも標準

正解 0 / 4問

Q1. 身長データ 160, 165, 170, 175, 180（cm）の「標準偏差」（n−1で割る方式）はおよそいくらでしょう？

解説を見る
平均170cm。偏差の2乗の合計は 100+25+0+25+100=250。不偏分散 = 250÷(5−1) = 62.5、標準偏差 = √62.5 ≒ 7.9cm です。

Q2. 上のデータの「分散 = 62.5」の単位は何でしょう？

解説を見る
偏差（cm）を2乗して足したので単位は cm² になります。そのため最後に平方根を取って標準偏差（cm）に戻して使うのが一般的です。

Q3. 不偏分散では n で割らず「n−1」で割ります。その理由として正しいのはどれでしょう？

解説を見る
サンプルのばらつきは母集団のばらつきより小さくなりがちで、n で割ると母分散を平均的に過小評価します。n−1 で割ることで偏りなく推定できます。

Q4. データ [8, 8, 8, 8] の標準偏差はいくらでしょう？

解説を見る
すべての値が平均(8)と同じなので、偏差は全部0。標準偏差は0になります。全データが同じ値のときだけ標準偏差は0です。
