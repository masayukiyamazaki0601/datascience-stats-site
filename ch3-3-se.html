Chapter 03 / Unit 03 — 推定の道具をそろえる

標本平均の分布と標準誤差：推定値はどれくらい「あてにならない」？

このUnitでできるようになること
  • 標本平均 x̄ が「標本をとるたびに変わる確率変数」だと説明できる
  • 標準誤差 SE = σ ÷ √n の意味と、σ（データのばらつき）との違いを説明できる
  • サンプルサイズ n を大きくすると標準誤差が小さくなる理由を説明できる
  • σ が未知のときは s ÷ √n で標準誤差を推定できる
Step 01

標本平均は、とるたびに変わる「確率変数」

あなたはECサイトの運営者です。知りたいのは、お客様全員（母集団）の1回あたりの平均購入額 μ。でも、全注文を集計するのは大変。そこで無作為に50件の注文（標本）を抽出して、その平均 x̄ を計算しました。

1回目の標本 → x̄ = 5,320円（この1つの値で μ を推定！）

ここで質問です。もし明日、べつの50件を無作為に抽出し直したら、x̄ は同じ 5,320円になるでしょうか？

答えは「ならない」です。標本に選ばれる注文が変われば、平均も少し変わります。x̄ は「母集団から標本をとるたびに値が変わる」——つまり x̄ は確率変数です。いっぽう μ は変わりません。μ は「真の値（母数）」、x̄ はその「当て推量（推定値）」でしたね（Unit②）。

「標本のとり方の偶然」で x̄ がブレる——このブレをうまく扱えるかどうかが、これからの推定・検定のすべての土台になります。

✏️ 途中確認 — x̄ の正体

母集団から無作為に標本をとり直すたびに、標本平均 x̄ はどうなるでしょう？

答えの理由
x̄ は、どの50件を選ぶかという「偶然」で変わる確率変数です。だから x̄ を1回計算しただけでは、μ からどれくらいズレているか分かりません。その「ズレの大きさ」を測る道具が、このUnitの主役です。
Step 02

標本平均を何度も集めると「標本分布」が見える

「標本をとって x̄ を計算する」作業を、仮に1000回くり返したらどうなるでしょう。x̄ が1000個集まります。

この x̄ たちをヒストグラムにすると、ある分布が現れます。これを標本分布（sampling distribution）と呼びます。注意したいのは、「標本そのものの分布」ではなく「標本平均 x̄ の分布」だということです。

図1: 中心は同じ μ なのに、個々のデータ X は広く（σ=10）、その平均 x̄ は狭い。n=16 なら 広がりは σ÷√n = 10÷4 = 2.5 まで縮む

図の2つのベルを比べてください。個々のデータ X は広く散らばります（1件1件の購入額はバラバラ）。ところが 平均 x̄ は、中心 μ のまわりにずっと狭く集まる。平均をとると、大きめの値と小さめの値が打ち消し合うためです。

つまり標本分布には、次の2つの性質があります。

  • 中心 = μ（Unit②の不偏性 E(x̄) = μ そのもの）
  • 広がり = 個々のデータよりずっと小さい

✏️ 途中確認 — 標本分布の中心

標本平均 x̄ の分布（標本分布）は、どの値のまわりに集まるでしょう？

答えの理由
x̄ は「平均すると μ になる」不偏推定量でした（E(x̄) = μ）。だから標本分布の中心は母平均 μ です。いっぽう、その分布の「広がり」は μ ではなく、次のStepで定義する標準誤差が担います。
Step 03

標準誤差 SE = σ ÷ √n ——「x̄ の分布の広がり」に名前をつける

個々のデータ X のばらつきは σ（標準偏差）でした。では、「標本平均 x̄ の分布」の広がりは、どう表せるでしょう。第2章⑧で学んだ中心極限定理が答えをくれます。

n が大きいとき、x̄ の分布は近似的に正規分布になる。平均 = μ、標準偏差 = σ ÷ √n

この「σ ÷ √n」には特別な名前がついています。それが標準誤差（standard error：SE）です。

SE = σ ÷ √n　…　「標本平均 x̄ の標準偏差」のこと

ここがこのUnitでいちばん大切なポイント。σ と SE は、どちらも「標準偏差」なのに、指しているものが違います。

σ（母標準偏差）SE = σ ÷ √n（標準誤差）
何のばらつき？個々のデータ X標本平均 x̄
イメージ注文1件1件のバラつき「平均の見積もり」のブレ
標本サイズ n の影響受けないn が大きいほど小さくなる

たとえば σ = 10 の母集団なら……。n = 1（標本が1個）なら SE = 10 ÷ √1 = 10。これは「1個だけ見る＝個々のデータと同じ」なので当然です。n = 100 なら SE = 10 ÷ 10 = 1。100人の平均は、1人のデータよりずっと安定します。

✏️ 途中確認 — SE の計算

母標準偏差 σ = 20、標本サイズ n = 100 のとき、標準誤差 SE はいくつでしょう？

答えの理由
SE = σ ÷ √n = 20 ÷ √100 = 20 ÷ 10 = 2。100個の平均は、個々のデータ（σ=20）よりずっとブレが小さい、ということです。nが大きいほど√nも大きくなり、SEは小さくなります。
Step 04

標本サイズ n の効果 —— n を4倍にすると SE は半分

SE = σ ÷ √n をじっと見ると、標本サイズの「力」が見えてきます。

  • n = 4　→　SE = σ ÷ 2
  • n = 16　→　SE = σ ÷ 4（n を4倍にしたら SE は半分）
  • n = 100　→　SE = σ ÷ 10

つまり 標本サイズ n を4倍にすると、標準誤差は √4 = 2 で割った値＝半分になります。ただし √n でしか縮まないので、「調査人数を2倍にしたら精度も2倍」とはなりません（n を2倍 → SE は 1 ÷ √2 ≈ 0.71倍）。

なぜ √n なのか。理由はこうです。平均は「合計 ÷ n」。個々のデータが独立なら、n個の合計の分散は n × σ² になるので、それを n で割った x̄ の分散は σ² ÷ n。標準偏差に直すと σ ÷ √n になる、というわけです。

では、ここまでを「動く実験」で確かめましょう。

🧪 標準誤差シミュレーション — x̄ のばらつきを体感する

母集団は「平均 μ=50」の正規分布。σ（母集団のバラつき）はスライダーで変更できます。ここから n 個を無作為に抽出して平均 x̄ を計算する試行を繰り返し、x̄ の分布（ヒストグラム）を作ります。

試してみると分かります。σ を大きくするとヒストグラムは横に広がり（SE が大きくなる）、n を大きくすると縦に尖って狭くなります（SE が小さくなる）。そして「実際のx̄のばらつき」の数字が、理論 SE = σ÷√n に近づいていくのを確認できます。

✏️ 途中確認 — n の効果

標本サイズ n を4倍にすると、標準誤差 SE はどうなるでしょう？

答えの理由
SE = σ ÷ √n なので、n を4倍すると √4 = 2 で割った値＝半分になります。調査人数を増やすほど推定は安定しますが、「4倍の人」でやっとブレが半分、というのが統計の現実です。
Step 05

現実は σ が不明 → 推定標準誤差 s ÷ √n

ここまで、SE = σ ÷ √n と、σ（母標準偏差）を知っている前提で話してきました。でも現実には、母集団が分からないのですから、σ も分かりません。

そこで Unit② で準備した道具を使います。標本から計算した不偏分散 s² の平方根 s（標本標準偏差）を σ の代わりに使い、標準誤差を推定します。

推定標準誤差 = s ÷ √n　（s = √s²、s²は分母 n−1 の不偏分散）

実務では、これを単に「標準誤差」と呼ぶことがほとんどです。計算例を見てみましょう。

例: 注文50件の標本で推定する

x̄ = 5,320円、不偏分散から s = 1,250円 だったとします。すると、

推定SE = 1,250 ÷ √50 ≈ 1,250 ÷ 7.07 ≈ 177円

これは「推定値 x̄ = 5,320円 は、母平均 μ からだいたい ±177円くらいのズレを見込んだ値」という意味です。

s は n が大きくなるほど σ に近づきます（Unit②の「一致性」）。ただし n が小さいときは、s 自身もブレるので、その扱いは Unit⑥（t分布）で学びます。

✏️ 途中確認 — σ が分からないとき

母標準偏差 σ が分からない現実では、標準誤差 SE をどう見積もるでしょう？

答えの理由
σ は標本からは直接わからないので、不偏分散 s² の平方根 s（標本標準偏差）で代用します。SE ≈ s ÷ √n が「推定標準誤差」です。実務で「標準誤差」と言ったら、ふつうはこの推定値のことを指します。
Step 06

Python で「1つの標本」から x̄ と SE を出す

実務で手元にあるのは「1つの標本」だけです。その標本から x̄（点推定値）と s、そして推定標準誤差 s ÷ √n を計算します。pandas / NumPy でやってみましょう。

import numpy as np
# 例: あるお店の注文金額（円）30件 ＝ 手元にある1つの標本
x = np.array([640, 760, 850, 980, 1200, 1200, 1500, 2100, 3400, 8900,
              720, 830, 940, 1080, 1120, 1350, 1420, 1680, 1950, 2200,
              1180, 1290, 1360, 1490, 1580, 1740, 1820, 1990, 2140, 2310])
n = len(x)
x_bar = x.mean()        # 標本平均 x̄ → 1724.0
s = x.std(ddof=1)      # 標本標準偏差(分母n−1) → 1479.4
se = s / np.sqrt(n)     # 推定標準誤差 s÷√n → 270.1

pandas なら Series.sem() という関数で s ÷ √n を1発で出せます（内部では分母 n−1 の s を使って計算します）。

import pandas as pd
pd.Series(x).sem()   # → 270.1（x̄のブレの目安）

この「SE ≈ 270円」は、x̄ = 1,724円という推定値が、母平均 μ からおおよそ ±270円くらいズレる可能性があるというサインです。SE が小さい推定ほど「当てになる」——データサイエンスの現場（A/Bテストや精度評価）でも、この感覚がずっと使われます。

✏️ 途中確認 — pandas の関数

pandas で「標本平均 x̄ のブレ（標準誤差 s÷√n）」を直接計算できるメソッドはどれでしょう？

答えの理由
sem() は standard error of the mean の略で、分母 n−1 の標本標準偏差 s を使って s ÷ √n を返します。x̄ の「ブレの目安」が1行で出せるので、結果を報告するときに便利です。
Step 07

まとめ: 「点推定」に誤差のモノサシをそろえた

このUnitで出てきた道具を、1つの表にまとめました。

用語意味式
標本平均 x̄μ の点推定値（不偏推定量）標本の合計 ÷ n
母標準偏差 σ個々のデータ X のばらつき母集団の標準偏差
標準誤差 SEx̄ の分布（標本分布）の標準偏差σ ÷ √n
推定標準誤差σ が不明なときの SE の見積もりs ÷ √n（s は分母 n−1）

ここまでの流れを言葉にすると、こうなります。

「x̄ は、母平均 μ からだいたい ±SE くらいズレる」——これを数値で言えるようになった

1つの標本から計算した x̄ だけでは、それが μ に近いかどうか分かりません。しかし SE を添えれば、「この推定値はこれくらいブレる可能性がある」という当てにならなさのモノサシになります。

実務のコツ（1行）

「平均 1,724円（SE = 270円）」のように、推定値には SE を添えて報告しましょう。「±SE」が小さいほど、その推定は信頼できます。

そして、いよいよ次が推定の本番です。SE が手に入ったので、「μ は 1,724 ± 270 × 1.96 くらいの範囲にある」と、値ではなく範囲で母平均を推定できます。それが Unit④の区間推定（95%信頼区間）です。

✏️ 途中確認 — まとめ

標準誤差 SE について正しい説明はどれでしょう？

答えの理由
SE は「x̄ の分布（標本分布）の標準偏差」。σ ÷ √n で、σ が分からなければ標本標準偏差 s を使って s ÷ √n と推定します。SE が小さいほど、推定値 x̄ は μ の近くに集まります。

📝 第3章ユニット③の確認クイズ（6問）

正解 0 / 6問

Q1. 標準誤差（SE）は、何の「ばらつき」を表す値でしょう？

解説を見る
σ が「個々のデータ X のばらつき」なのに対し、SE は「標本をとるたびに変わる x̄ のばらつき」です。x̄ の分布の標準偏差のことを標準誤差と呼びます。

Q2. 母標準偏差 σ = 15、標本サイズ n = 9 のとき、標準誤差 SE はいくつでしょう？

解説を見る
SE = σ ÷ √n = 15 ÷ √9 = 15 ÷ 3 = 5。9個の平均は、個々のデータ（σ=15）の3分の1のブレになります。

Q3. 標本サイズ n を4倍にすると、標準誤差 SE はどうなるでしょう？

解説を見る
SE = σ ÷ √n なので、n を4倍にすると √4 = 2 で割った値、つまり半分になります。「人数を2倍にしても精度は2倍にならない（√2倍しか改善しない）」点が実務では重要です。

Q4. 母標準偏差 σ が分からないとき、標準誤差をどう見積もるでしょう？

解説を見る
母集団が分からない以上 σ も不明なので、分母 n−1 の不偏分散から求めた標本標準偏差 s で代用します。s ÷ √n を「推定標準誤差」と呼び、実務では単に標準誤差（SE）と呼びます。

Q5. SE = σ ÷ √n に n = 1（標本が1個だけ）を入れると、SE はどうなるでしょう？

解説を見る
n = 1 なら SE = σ ÷ √1 = σ。「標本が1個」＝個々のデータを1つ見ているのと同じなので、ブレは σ のまま。平均をとる意味が出てくるのは n が2以上になってからです。

Q6. 「平均購入額 x̄ = 1,724円（SE = 270円）」という報告の、SE = 270円の意味として正しいのはどれでしょう？

解説を見る
SE は「x̄ の分布の標準偏差」。標本をとり直したら x̄ は μ のまわりを ±SE くらい動く、という意味です。個々のデータのばらつき（σ）と混同しないように。次Unitではこの SE を使って μ の「範囲」を推定します。
