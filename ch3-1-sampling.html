Chapter 03 / Unit 01 — 母集団と標本・サンプリング

母集団と標本：全体を調べずに「全体」を推し量る

このUnitでできるようになること
  • 母集団と標本のちがいを説明できる
  • 「無作為抽出」がなぜ必要なのかを説明できる（偏り＝バイアスの問題）
  • 標本から母集団を「推定」する流れを説明できる
Step 01

「全員に聞けない」から、統計学が始まる

第2章では「確率分布」「正規分布」「中心極限定理」という道具を身につけました。ここからは、いよいよ現実の調査・データ分析でそれらを使います。たとえば次のような質問に答えたいとしましょう。

  • このECサイトの利用者全体の平均購入額はいくらか？
  • 全国の有権者のうち、政策Aを支持する人は何%か？
  • 新しく出した商品の「満足度」の平均はどのくらいか？

本当に正確に知りたいなら全員に聞けばよいですが、それは現実的ではありません。全員に聞くには時間とお金がかかりすぎます（国勢調査のような全数調査は特別な例）。そこで、一部の人（標本）を調べて、全体（母集団）を推し量る、という方法を使います。これを統計学では推測統計と呼びます。

第3章ではこの推測の流れを、次の順で学びます。

  1. 母集団と標本・無作為抽出（本Unit）
  2. 点推定（1つの値で当てる）と不偏推定量（Unit②）
  3. 区間推定・95%信頼区間（Unit④〜⑥）

ポイントは、「推測には必ず誤差がつきまとう」こと。このUnitでは、まず誤差をできるだけ小さく・正しくするための土台「どうやって標本を選ぶか」を学びます。

Step 02

「母集団」と「標本」。知りたいのは母集団

まず用語を整理します。統計学では、調べたい対象すべてを母集団（population）、そこから実際に調べる一部を標本（sample）と呼びます。たとえば「ECサイトの利用者全体」が母集団で、「アンケートに答えた100人」が標本です。

  • 母集団の平均 μ（母平均）: 本当に知りたい値。でも通常は直接測れない
  • 標本の平均 x̄（標本平均）: 実際に計算できる値。これを使って μ を推定する

流れを図にすると次の通りです。

図1: 母集団（μは不明）→ 無作為抽出 → 標本（x̄を計算）→ 母平均を推定。この流れが第3章全体のテーマ

ここで、母集団が「人」でなくても同じ考え方です。「この工場で今日作った製品全部」が母集団で、「検査した100個」が標本。「今年の全注文データ」が母集団で、「分析に使う一部」が標本、という具合です。データ分析では、手元のデータはたいてい「母集団の一部（標本）」だという意識を持つことが大切です。

✏️ 途中確認 — 母集団と標本

「全国の20〜30代の全員の平均年収を知りたい」と思い、無作為に選んだ2,000人に調査しました。このときの母集団はどれでしょう？

答えの理由
母集団は「調べたい対象すべて」＝全国の20〜30代全員です。回答した2,000人はその中から選んだ標本です。知りたいのは母集団の平均で、標本はその手がかりです。
Step 03

なぜ「無作為抽出」が大事なのか：偏りの問題

母集団の一部を調べるとき、選び方に偏りがあると、その時点で結果はゆがみます。たとえば次のような「調査」は危険です。

  • 駅前で声をかけて集めた人だけに聞く（歩いている人に偏る）
  • SNSで「アンケートに答えて！」と呼びかける（興味がある人だけが答える）
  • 自分に都合のよい相手（友人・常連客）にだけ聞く

このように、母集団を代表していない標本になることを偏り（バイアス）があると言います。偏りがあると、標本サイズをどれだけ大きくしても間違いは解消されません。そこで使うのが無作為抽出（ランダムサンプリング）です。母集団の全員に番号をふって、くじ引きや乱数で「どの人も同じ確率」で選ぶ方法です。

図2: 24人の母集団。塗られた7人がくじで選ばれた標本。誰もが同じ確率で選ばれる＝偏りが出にくい

無作為抽出にはいくつか種類があります（単純無作為抽出＝くじ引きが基本／層化抽出＝グループごとに分けてから抽出 など）。まずは「全員に同じ確率」という単純無作為抽出の考え方を押さえておけば十分です。

✏️ 途中確認 — 無作為抽出の目的

調査で無作為抽出を行う目的として、もっとも適切なものはどれでしょう？

答えの理由
無作為抽出の目的は「母集団を代表する（偏りのない）標本」を得ることです。アのように必ず一致するわけではありません（そこに標本誤差が残ります）。
Step 04

標本平均はどれくらい当たる？＝標本誤差の大きさ

無作為抽出をしても、標本平均 x̄ は母平均 μ とぴったり一致するわけではありません。この「たまたま選んだ標本によるズレ」を標本誤差（サンプリング誤差）と呼びます。ただし第2章Unit⑧で学んだ通り、そのズレの大きさは理論的にわかっています。

x̄ の標準偏差（標準誤差）= σ ÷ √n　→　n が大きいほど誤差は小さくなる

σ = 1 の場合に、標本サイズ n と標準誤差の関係をグラフにすると次のようになります。

図3: n を増やすと標準誤差は小さくなる。ただし曲線は「ゆっくり」下がる（nを4倍→誤差1/2、nを16倍→誤差1/4）

標本誤差は無作為抽出なら避けられないが、n を増やせば減らせて、しかも大きさを数学的に見積もれる、という点が重要です。次Unit以降の「推定」は、この「誤差の大きさがわかる」ことを土台にしています。

✏️ 途中確認 — 標本サイズの効果

標準誤差 SE = σ ÷ √n です。σ をそのままに、標本サイズ n を10人から40人（4倍）にすると、標準誤差はどうなりますか？

答えの理由
√40 ÷ √10 = √4 = 2 なので、標準誤差は 1/2 になります。「誤差を半分にしたければ標本を4倍に」が実務の目安です。

「一部から全体を推し量る」感覚をシミュレーションで確かめてみましょう。母集団のうち30%が新商品を「支持」しているとします（真の値 p=0.3）。無作為に n 人聞いて「支持する割合」を計算する試行を繰り返します。

Step 05

誤差には2種類ある：「標本誤差」と「非標本誤差」

調査結果が母集団からズレる原因は、実は2種類あります。

標本誤差（サンプリング誤差）非標本誤差
原因全体ではなく一部しか調べないため偏った選び方・無回答・測定ミス・回答のウソなど
n を増やせば小さくなる小さくならない（偏りは残る）
対処n の設計・誤差の範囲を報告調査設計（無作為抽出・質問の工夫・回収率向上）

たとえば「SNSで呼びかけたら、回答した人が全員ヘビーユーザーだった」というのは、n を増やしても直らない非標本誤差（選択バイアス）です。「全数調査なら誤差ゼロ」と思うかもしれませんが、全数調査でも測定ミスや記入漏れ（非標本誤差）は残ります。

よい調査・よい分析のフローは、次のようなものです。

  1. 母集団を明確に定義する（誰について言いたいのか）
  2. 無作為抽出の方法を決める（単純無作為・層化など）
  3. 調査票・測定方法を設計する（わかりやすい質問・選択肢の偏りを避ける）
  4. 実施し、回収率を上げる努力をする（無回答はバイアスになりうる）
  5. 結果は誤差つきで報告する（「約○%±○%」のように。→次Unit以降）

✏️ 途中確認 — 誤差の分類

SNSでアンケートを呼びかけたら、回答が「やる気のあるユーザー」に偏ってしまいました。これはどちらの問題でしょう？

答えの理由
「答えたくなる人」が偏って選ばれているので、これは非標本誤差（選択バイアス）です。人数を増やしても直りません。無作為抽出と調査設計で防ぎます。
Step 06

まとめ: このUnitで身につけた道具

  • 母集団 = 調べたい対象すべて（本当に知りたいのはこちら）／標本 = 実際に調べる一部
  • 母平均 μ は未知。標本平均 x̄ は計算でき、そのズレ（標本誤差）は σ÷√n で見積もれる
  • 無作為抽出 = 誰もが同じ確率で選ばれる抽出。母集団を代表する標本の土台
  • 偏り（バイアス）は n を増やしても直らない。非標本誤差は調査設計で防ぐ
  • 結果は必ず「誤差つき」で報告する（次Unit以降の推定へ）
用語意味例
母集団 population調べたい対象すべて全国の20〜30代全員
標本 sample実際に調べる一部無作為に選んだ2,000人
母平均 μ母集団の平均（通常は未知）平均年収 μ は？
標本平均 x̄標本から計算できる平均2,000人の平均年収 x̄
無作為抽出全員に同じ確率で選ばれる抽出くじ引き・乱数
標本誤差一部だけ調べるために生じる誤差SE = σ ÷ √n で見積もる
非標本誤差（バイアス）偏った選び方・無回答などによるズレSNS募集・駅前調査

データ分析の現場では「このデータは母集団の何を代表しているのか？」「どうやって集められたのか？」を常に確認することが、結果の信頼性を左右します。

次はUnit②「点推定と不偏推定量」です。標本平均 x̄ で母平均 μ を「1つの値」として当てる方法と、なぜ標本平均が良い推定量なのか（そして分散の「n−1」の謎）を解きます。

📝 第3章ユニット①の確認クイズ（5問）

正解 0 / 5問

Q1. 「全国の高校生の平均睡眠時間を知りたい」と思い、無作為に選んだ500人に調査しました。母集団はどれでしょう？

解説を見る
母集団は「調べたい対象すべて」＝全国の高校生全員。500人はそこから選んだ標本です。知りたいのは母集団の平均 μ で、標本平均 x̄ はその推定に使います。

Q2. 標本平均 x̄ について正しい説明はどれでしょう？

解説を見る
標本平均は標本ごとにブレる確率変数ですが、その期待値は母平均 μ（不偏性）。ばらつきは SE = σ/√n で表されます。

Q3. 無作為抽出のもっとも重要な目的はどれでしょう？

解説を見る
無作為抽出の目的は、全員に同じ確率で選ばれることで「母集団を代表する標本」を得ること。偏った標本からは正しい推定ができません。

Q4. 母標準偏差 σ = 12 のとき、標本サイズ n を25人から100人（4倍）にすると、標準誤差 σ/√n はどうなりますか？

解説を見る
n=25 なら 12÷5=2.4、n=100 なら 12÷10=1.2。n を4倍にすると標準誤差は1/2になります。

Q5. 「全数調査（母集団全員に調査）なら、誤差は必ずゼロになる」という主張について、正しいのはどれでしょう？

解説を見る
標本誤差（一部しか見ないことによる誤差）は全数調査ならなくなりますが、質問の意図の取り違えや記入ミスなどの非標本誤差は残ります。
