分布の形・外れ値・標準化

このページでできるようになること
  • ヒストグラムの形からデータの特徴を読み取れる
  • 外れ値への正しい対応（まず原因調査）を説明できる
  • zスコアを計算し、単位の違うデータを比べられる
Step 01

1.6 分布の「形」を読む: ヒストグラムと歪み

数値の要約（平均・標準偏差）の前に、まずデータの形を見る習慣が大切です。「数値だけに頼らず、まず描け」がデータ分析の鉄則です。量的データの形を見る定番はヒストグラムです。

1.6.1 例Aの注文金額をヒストグラムにすると

import numpy as np
import matplotlib.pyplot as plt
orders = np.array([640, 760, 850, 980, 1200, 1200,
                   1500, 2100, 3400, 8900])  # 例Aと同じデータ
plt.hist(orders, bins=[0, 1000, 2000, 3000, 4000, 5000, 9000],
         edgecolor="white")
plt.xlabel("注文金額 (円)"); plt.ylabel("件数"); plt.show()

描いてみると、1000円前後に注文が集中し、右側（高い金額）にだらりと裾が伸びる形になります。この形を「右の裾が長い（右に歪んだ）分布」と呼びます。年収データやサイトの滞在時間など「下限はあるが上限がない」データでよく見られる形です。

分布の形特徴代表値の関係実例
左右対称（山型）平均を中心に左右バランス平均 ≈ 中央値 ≈ 最頻値身長、測定誤差、製造工程の寸法
右の裾が長い（正に歪む）高い側に外れ値が伸びる平均 > 中央値年収、注文金額、SNSフォロワー数
左の裾が長い（負に歪む）低い側に外れ値が伸びる平均 < 中央値簡単すぎるテストの点数（高得点に集中）
二峰（山が2つ）性質の違う集団が混ざっている可能性—男女混合の身長データ（⇒ 層別の必要性を示唆）
実務での使いどころ: 「層別」の発想 ヒストグラムが二峰になったら、データの中に性質の違うグループが混ざっていないか疑います。たとえば「全社員の年収」が二峰なら、それは「正社員とアルバイト」の違いかもしれません。全体を1つにまとめる前に、グループ（層）に分けて見ることを層別と呼び、データ分析の基本動作です。
Step 02

1.7 外れ値にどう向き合うか

例Aの8900円のように、他のデータから極端に離れた値を外れ値（異常値）と呼びます。外れ値が見つかったら、まず「なぜ出たのか」を考えるのが鉄則です。

1.7.1 外れ値の「見つけ方」

  • IQR法: Q1 − 1.5×IQR 〜 Q3 + 1.5×IQR の範囲外（1.4で計算した方法。例Aでは8900円が該当）
  • zスコア法: 平均から標準偏差の3倍以上離れているか（次節1.8で説明）
  • 可視化: 箱ひげ図・散布図で目視する

1.7.2 外れ値の「原因」と「対応」

原因例対応の考え方
① 記録ミス・入力ミス年齢が「-3」、金額が1桁間違い削除 or 正しい値に修正
② 測定機器の故障・不正センサーの一時的な異常値削除（ただし根拠を記録しておく）
③ 本物の「珍しいけど正しい」値例Aの8900円（記念品のまとめ買い）むやみに消さない。影響を和らげたいなら対数変換や中央値ベースの指標へ
④ 別のグループの混入法人注文が個人向け分析に混ざった層別して分けて分析する
外れ値を勝手に消すのはNG 「外れ値があるから削除」は最後の手段です。本物の外れ値には「重要な意味」があることが多く、たとえばクレジットカードの不正検知では「ほかの人と違う使い方」こそが検知の手がかりになります。「外れ値 = ゴミ」ではなく、「外れ値 = 調査対象」という姿勢を持ちましょう。削除する場合は、いつ・なぜ削除したかを必ず記録します。
Step 03

1.8 単位の違うデータを比べる: 標準化（zスコア）

「数学65点」と「英語75点」、どちらの成績が良いでしょうか？「75点のほうが高いから英語」と即断するのは危険です。 クラスによって平均点やばらつきが違うからです。データを平均0・標準偏差1に変換して比べるのが標準化（zスコア）です。

\[ z = \frac{x - \bar{x}}{s} \]

zスコアは「平均から標準偏差いくつ分、離れているか」を表します。z=1なら「平均より標準偏差1個ぶん上」。単位（点・円・cm）が消えるので、どんなデータでも同じ物差しで比べられます。

1.8.1 具体例: 太郎くんの試験結果

科目太郎の得点 \(x\)クラス平均 \(\bar{x}\)標準偏差 \(s\)zスコア
数学65点50点15点(65−50)/15 = 1.0
英語75点70点10点(75−70)/10 = 0.5

絶対点数の「75点」だけ見ると英語が上ですが、クラス内での相対的な位置は数学（z=1.0）のほうが上です。面接などで「偏差値」という言葉を聞いたことがあると思いますが、偏差値はこのzスコアを 偏差値 = 50 + 10×z で変換したものです（z=1.0 は偏差値60）。

1.8.2 実務での使いどころ

  • 機械学習の特徴量スケーリング: 「身長cm（単位は100前後）」と「年齢（単位は数十）」のように単位の違う特徴量をそのまま機械学習に入れると、値の大きな特徴量がモデルを支配してしまいます。StandardScaler などで標準化するのは、この1.8の考え方です。
  • 外れ値の目安: |z| > 3（平均から標準偏差3個分以上）を外れ値候補とする方法（1.7で紹介したzスコア法）
  • 異なる指標の比較: 売上（円）と来店数（人）のように単位の違うKPIの動きを並べて見るとき
import numpy as np
math_scores = np.array([20,35,40,50,55,60,65,75])
z = (math_scores - math_scores.mean()) / math_scores.std(ddof=1)
print(z.round(2))  # 平均が0, 標準偏差が1 に変換される

正解 0 / 6問

Q1. 年収データのヒストグラムは「右の裾が長い（右に歪んだ）」形になることが多いです。このとき平均と中央値の関係はどうなりますか？

解説を見る
高い側の外れ値に引っ張られる平均は中央値より大きくなります（平均 > 中央値）。所得の平均値が実感とずれる理由がここにあります。

Q2. ヒストグラムが「二峰（山が2つ）」になったとき、最初に疑うべきことは何でしょう？

解説を見る
性質の違うグループ（例: 男女、正社員とアルバイト）が混ざっている可能性があります。全体を1つにまとめる前に、グループ（層）に分けて分析するのが基本です。

Q3. 外れ値（例: 注文データの8900円）が見つかったとき、最初にやるべきことは何でしょう？

解説を見る
「なぜこの値が出たのか」を調査します。入力ミスなのか、本物の珍しい値なのか、別グループの混入なのかで対応が変わります。むやみに削除してはいけません。

Q4. 太郎くんは数学65点（クラス平均50・標準偏差15）、英語75点（クラス平均70・標準偏差10）でした。クラス内での相対的な成績が良いのはどちらでしょう？

解説を見る
zスコアで比べます。数学 (65−50)÷15 = 1.0、英語 (75−70)÷10 = 0.5。平均からより離れて上位にいる数学のほうが相対的に優秀です。

Q5. データを標準化（zスコア変換）すると、変換後の平均と標準偏差はどうなりますか？

解説を見る
各値から平均を引いて標準偏差で割るため、変換後は「平均0・標準偏差1」になります。単位の違うデータ同士を同じ物差しで比べられるようになります。

Q6. 外れ値の目安として「|z| > 3」を使う方法があります。これはどんな意味でしょう？

解説を見る
zスコアは『平均から標準偏差いくつ分離れているか』。|z| > 3 は平均から標準偏差3個分以上離れた値で、左右対称な山型分布ではほぼ出ないため外れ値候補とみなします。
